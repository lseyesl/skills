# 实时资产优化与功能回归

适用：图片还原后准备交付，或已有经过范围验收的源模型，需要降低加载、运行、纹理或动画成本。先读 [游戏资产](../../game-assets.md) 与 [glTF 验证](gltf-validation.md)。依据：[meshoptimizer / gltfpack](../../sources/production-sources.md)。

## 先验收并冻结源模型

1. **检查还原源模型**：回原始照片而非只看生成 A，逐模块检查轮廓/比例、曲率、负空间、连接、配件和标记，运行几何/用途检查。用现有 `validate_module_ledger.py source-ledger.json --stage final --output source-ledger-report.json` 核验声明；该工具只检查证据声明，必须实际查看原图与真实渲染，不能把自动记录完整当成视觉通过。源模型仍有主要缺陷时，返回还原步骤；诊断性试减面可执行，但不作为已接受的优化基准。
2. **冻结**：源模型通过约定还原范围后，另存不覆盖的 source.blend，保留账本、原图对照和结构报告；记录源文件/账本/证据哈希。复制 [优化计划模板](../../../assets/optimization-plan-template.json)，填写源路径、范围、目标消费者和预算。不修改唯一源文件，不在失败报告冻结后修模型补分。
3. **预设损失门槛**：固定相机/灯光/尺度和动画帧，在原图控制区域声明可观察的允许误差。例如勺柄宽度及支撑摆放、把手根部过渡、轮毂孔形/孔面积/曲面鼓度、胎肩轮廓、胎纹/文字、关节形变。容差来自任务，不设置一个通用相似度就放行。未批准的简化不能因为“次要细节”而自动删除。
4. **派生候选**：用不同文件路径制作优化副本，保留初候选和额度内修正。源模型已满足目标成本时，不强制减面，仍验证交付副本。优先局部减面、重拓扑、共享重复几何、贴图烘焙或 LOD；远景细节可转贴图，但在目标屏幕尺度检验，影响轮廓/负空间/功能的部分不能直接抹去。
5. **双重对照**：优化副本既对冻结源模型检查损失，也回原图检查身份，避免忠实保留一个原本错误的基准。按同相机的全局视图和关键局部对照、截面、连接、实际动作及独立导出重载逐项验证。细分减少、源多边形减少或文件变小不替代实际求值三角面/消费者成本。
6. **判定与交付**：源哈希保持、所有保护项通过、目标收益达到且最终预算符合才接受。任何保护项失败为负向，未检查为无法判断；记录哪些改进/不变/变坏，而不只给总分。预算内无法兼顾时交付源模型与被拒候选/冲突说明，不自动降低保真标准或抬高预算；用途取舍需已有明确授权。优化副本通过后才由交付适配器按最终上限验收。

源模型的还原分、优化副本的还原分、几何/功能与成本分别记录。源模型超过最终面数不否定源还原质量；交付副本超过最终面数仍未达标。增加面数也不等于曲面、拓扑或还原自动正确。

## 先定义收益

冻结基线、目标消费者版本、代表镜头/屏幕尺度、动画和运行设备。声明本次主目标、允许误差与保护项：可查询节点/挂点、材质身份、动作、形态键、轮廓、接触、纹理和可编辑源。记录实测文件大小、三角形、材质/调用、加载及运行成本；面数是指标之一，不能替代性能。

| 瓶颈 | 可尝试的路径 | 重要回归 |
|---|---|---|
| 下载/资源尺寸 | 纹理或几何压缩、移除无用资源 | 解码扩展支持、加载峰值内存、图像/动画误差 |
| 实例/重复几何 | 实例化/共享网格 | 消费端支持、独立操作与材质差异 |
| 几何开销 | 用途适配的减面/LOD | 屏幕尺度轮廓、阴影、蒙皮和接触 |
| draw calls/节点开销 | 材质/网格合并 | 节点身份、交互拾取、动画与挂点 |
| 动画尺寸 | 量化/重采样 | 关键接触、循环接缝、根运动与驱动效果 |

gltfpack 等工具可能合并节点/材质、裁剪节点树和重采样动画。需要按名称操作时明确保留规则；元数据、扩展和精度同样要核对，不盲用默认。它是可选后端，不在本 Skill 内自动安装或执行。

先在派生文件上做单项候选，记录命令和版本。按 [交付与优化验收](../../acceptance/gltf-delivery.md) 跑规范、重载、消费者和功能回归。[production_checks.py](../../../scripts/production_checks.py) 的 optimization_result 仅帮助判断已声明的数值收益与保护项，unknown 不能算通过；它不替代真实测量和视觉审阅。

保护项退化则回滚或缩小适用范围；成本目标未达到或测量不足保持未证实。优化输出不替换唯一可编辑源。
