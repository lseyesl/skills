# 中国神话视频项目工作流配置

本页是活动 profile、默认值、兼容矩阵和工作流路由的唯一权威来源。它不定义状态、门槛、资产所有权或专业做法。

> [!important] 解析规则
> 尚未绑定的新项目读取 frontmatter 中的 `active_visual_profile` 与 `active_implementation_profile`。已有项目永远读取自己的锁定项目配置；项目默认变化不自动迁移历史项目。同一 `story_id` 的另一套视觉风格必须建立新的项目目录和新的 `project_id`，不得在原项目切换或混用风格。

主题锁定的 profile 选择和既有资产路径保持不变；[跨仓库资产所有权](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E8%B7%A8%E4%BB%93%E5%BA%93%E8%B5%84%E4%BA%A7%E6%89%80%E6%9C%89%E6%9D%83.md)中的当前操作安全／提效协议属于项目全局约束。现有主题在本协议生效后新建或实质返修的资产版本使用稳定路径与 manifest 状态，不需要仅为采用提效协议更换视觉或实现 profile，也不迁移已存在的历史资源。

## 主题绑定

新项目首次进入正式视觉设计前创建：

```text
项目/<项目>/制作/主题工作流配置-v1.md
```

至少锁定：

```yaml
workflow_config: "[工作流-项目配置](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E9%A1%B9%E7%9B%AE%E9%85%8D%E7%BD%AE.md)"
project_config_version: v23
project_id: <stable-ascii-story-and-style-id>
story_id: <stable-ascii-myth-id>
vault_project_path: projects/中国神话视频/项目/<项目>
visual_profile: <profile>
visual_profile_version: <version>
implementation_profile: <profile>
implementation_profile_version: <version>
repository_id: <registered-id>
source_locale: zh-CN
locales:
  - zh-CN
  - en-US
```

`project_id` 必须稳定、ASCII kebab-case 且包含风格区分；例如 `jingwei-fills-the-sea-paper-theater`。建立绑定前必须验证：两个 profile 均为 `active`、互相兼容、仓库已登记、目标后端主入口存在，且后端资源根将使用该 `project_id`。项目锁定后，项目配置升级不会自动改变该项目。

## 配置切换

切换项目默认值或新增 profile：

1. 先登记仓库和单一后端主入口；
2. 完成兼容矩阵和最小环境验证；
3. 更新本页并提升 `config_version`；
4. 运行工作流校验器；
5. 独立提交；
6. 只影响之后新建、尚未绑定的主题。

同一项目不得改用其他 `visual_profile`。要为同一 `story_id` 制作另一风格，必须新建 `项目/<主题>-<风格>/`、新的 `project_id`、独立主题配置和独立后端资源根；不得改写旧配置，也不得复用旧项目的活动视觉或后端资源。

历史锁定配置缺少 `story_id` 或 `vault_project_path` 时，不批量篡改历史记录；它只能继续审计。该项目下次生成新后端资源前，先建立同一视觉 profile 的新配置版本补齐身份字段，再继续生产。
