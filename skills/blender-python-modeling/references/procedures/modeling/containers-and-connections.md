# 容器、连接和旋转结构的诊断与局部修复

适用：杯/碗/壳体底面缺失、把手浮空、轮毂辐条断开，以及基础体相交却未满足连接契约。不用于自动修复任意扫描网格或推断材料强度。

## 先声明连接的含义

记录单位、目标用途、独立/装配/连续表面关系、内部开口、厚度范围、端点、截面及重复数量。渲染资产允许独立装配件；打印实体、人物皮肤和铸造轮毂通常要求相应连续/封闭结构，不能统一用父子关系或包围盒重叠证明连接。截面和容差来自参考与用途，未知尺寸保持归一化并说明推断。

## 按观测选择处理

| 观测与区分检查 | 处理路径 | 重验范围 |
|---|---|---|
| 中心射线漏底、外围命中；旋转截面两端均为小正半径 | 检查是否把内外底圈连成了轴心通道；移除错误通道，并用正确极点扇面/平面封口连接底面 | 中心及多个内侧位置的两层命中、底厚、法线和所需封闭性 |
| 全部射线漏底或只有一层命中 | 确认相机/轴/射线起点在容器内部；再区分未建底面、单层薄片和薄面法线问题 | 实际求值网格、轴向截面及内外视图 |
| 把手端点到杯壁距离超过截面可达范围 | 先修路径端点及截面过渡；需要连续表面时桥接/焊接拓扑，不只拉长到相交 | 两端距离、连接拓扑、过渡阴影与把手负空间 |
| 辐条看似成组，但中心盘/轮圈到辐条无拓扑路径 | 检查内外半径、端点和连接截面；局部补桥接或在副本执行并检查布尔/重拓扑 | 每根辐条到中心及轮圈的路径、开口数量、截面和法线 |
| 连接存在但轮子转动时部件脱离或偏心 | 检查轮轴、父子变换和动画数据；修复运动层级，不先重建几何 | 0/90/180/270/360°实际转动、固定轮轴及导出 clip |

禁止对所有边界自动补洞：杯口、通风口和衣服开口可能有意存在。布尔、焊接和重拓扑在派生副本进行；保留源粗模及已确认的开口/材质边界，操作后重新检查。

## 可执行测量与边界

[construction_checks.py](../../../scripts/construction_checks.py) 提供只读测量：

- `endpoint_proximity(target, endpoints, radii, tolerance)`：实际求值表面的世界坐标距离。半径是显式世界单位下可达范围；距离通过不证明焊接或承载。
- `axial_floor(target, origins, direction, minimum=..., maximum=..., distance=..., epsilon=...)`：至少三条来自容器内部的明确射线，记录首/次命中及轴向间距。epsilon 必须小于最低厚度，起点不能放在杯壁或其他遮挡上。这不是全局最薄壁厚算法。
- `connected_regions(obj, regions, paths)`：在基网格中检查明确顶点区域之间是否存在边路径。区域应来自实际几何/标记，不能复制其他模型的顶点编号；不覆盖求值后的任意布尔，也不证明截面够粗。

配合 production_checks.inspect_mesh 的封闭/退化/有限性检查与实际截面图，不以一个标量代替所有结构验收。

## 失败后的执行闭环

先在任务记录预设最大修复次数/时间和保护项。每次保留快照、观察、原因假设、修改范围、数值结果和对应视图；只修改被证据否定的模块。修复后让旧 blockout/comparison 回执失效，重新生成 pending 草稿，实际检查后才登记。几何检查通过但形状不符时仍不能进入 final。

达到预算、无可靠结构解释或重复同类失败时，停止当前路线并记录缺口，重新选择结构方法；不删除失败重试，也不降低完成标准。验收依据见 [基础形体](../../acceptance/blockout.md) 与 [可用资产](../../acceptance/usable-asset.md)。
