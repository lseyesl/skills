# 中国神话视频导演工作流

本流程规定导演如何把已锁定的中文母版剧本转化为可执行的导演母版，并从 Gate 3 持续监督到 Gate 5。导演负责镜头叙事、节奏、表演、音画关系与成片品味，不负责静默改写剧本，也不代替技术人员实现代码。

上游：[中国神话视频编剧工作流](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E7%BC%96%E5%89%A7.md)

总控：[全流程总控工作流](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E5%85%A8%E6%B5%81%E7%A8%8B%E6%80%BB%E6%8E%A7.md)

> [!important] 核心原则
> **分镜锁定是导演监督的起点，不是导演职责的终点。**
>
> 每个镜头都必须说明：观众看见什么、为何从这个位置看、镜头结束时发生了什么变化，以及为何需要这段时长。不能把剧本文字机械切段后称为分镜，也不能用循环播放掩盖画面信息不足。
>
> “镜头里有某个元素”不等于“已经导演好这个元素”。凡会影响叙事、构图、动作、遮挡、连续性或观看焦点的角色、道具、景物、天气、特效和文字，都必须说明其空间位置、时间行为、交互关系与结束状态。

## 1. 职责、权限与边界

### 1.1 导演负责什么

- 从锁定剧本中提取叙事节拍、情绪变化和事实边界；
- 确定叙事视角、视觉语法、镜头组织、表演方式和音画节奏；
- 编制并锁定导演母版，包括分镜总表、关键镜头详解、全篇视觉故事板和全片 Animatic；
- 审查美术、素材、Remotion 实现、真实音频回填和最终成片是否忠于导演母版；
- 对实现中出现的镜头空洞、节奏失真和能力降级作出导演判断；
- 在 `项目/<主题>/制作/生产总控.md` 留下每次复审的状态、结论和下一步。

### 1.2 导演不负责什么

- 不静默修改神话事实、人物关系、因果、旁白或对白；需要改写时退回编剧流程；
- 不代替制片／总控维护全流程依赖、负责人和任务调度；
- 不代替技术实现者决定代码结构、渲染参数或底层组件；
- 不因技术方便而默认接受循环、静帧拉长、镜头合并或叙事删减。

### 1.3 决策权限

| 决策 | 主责 | 导演是否必须复审 |
|---|---|---|
| 事实、因果、旁白与对白改写 | 编剧 | 是 |
| 镜头增删、拆并、顺序和时长 | 导演 | 是，且必须记录 |
| 构图、景别、机位、表演、运镜和转场 | 导演 | 是 |
| 任务调度、依赖和交付状态 | 制片／总控 | 导演读取并给出专业状态 |
| 组件、数据结构和渲染实现 | 技术实现 | 仅在影响导演意图时复审 |
| 因工具能力造成的降级 | 技术提出，导演裁定叙事影响 | 是 |

## 2. 工作入口、产物与状态

### 2.1 何时进入导演流程

以下任务进入本流程：

- 把已确认剧本转换为分镜；
- 设计场景、景别、机位、构图、表演、运镜、转场和声音节奏；
- 修改现有分镜，并保持与指定剧本版本同步；
- 为美术、素材、动画和剪辑准备导演母版；
- 审查实现或成片是否符合既定导演方案。

如果只有调研笔记、资料包、选题或故事想法，应先进入编剧流程。剧本不是 `locked` 时，只能制作导演拆解、镜头策略或试拍段落，不得把全片分镜标为正式版本。

### 2.2 必需输入

1. 主题；
2. `项目/<主题>/脚本/` 中状态为 `locked` 的中文母版剧本；
3. 剧本中的制作规格、事实与改编边界、节拍、旁白和对白；
4. 已确认的画幅、目标时长和叙事形式；
5. 已有视觉资产和制作约束。尚未存在的资产必须标记为“待设计／待制作”。

开始前，在导演母版中记录：

| 字段 | 要求 |
|---|---|
| 锁定剧本 | `[[projects/中国神话视频/项目/<主题>/脚本/<剧本版本>]]` |
| 剧本状态 | 必须为 `locked` |
| 分镜范围 | 全片／幕／场景 |
| 目标时长 | 继承锁定剧本 |
| 画幅与分辨率 | 继承剧本或用户确认 |
| 表演形式 | 旁白主导／对白主导／混合 |
| 视觉方法 | 皮影／插画／动画／混合／待确认 |
| 制作限制 | 人力、资产、工具和表现边界 |

### 2.3 固定产物

```text
项目/<主题>/分镜/
├── 分镜总表-v1.md
├── 故事板总表-v1.md
├── 故事板/
│   ├── S001-P01.<图片格式>
│   └── ...
├── Animatic-v1.md
├── 审阅媒体/
│   └── Animatic-v1.<视频格式>
├── 序幕-<内容>.md
├── 第一幕-<内容>.md
├── 第二幕-<内容>.md
└── ...

项目/<主题>/制作/
└── 生产总控.md
```

- `分镜总表-v1.md` 是导演母版入口，记录整体视觉语法、镜头清单、总时长和版本绑定。
- 分幕文件保存逐镜表与关键镜头详解。
- `故事板总表-v1.md` 保存全镜覆盖矩阵、面板索引和镜头间连续性；每张图板使用稳定的 `镜号 + 面板号` 标识。
- `Animatic-v1.md` 记录由全部故事板组成的动态分镜版本、媒体路径、镜序、帧率、总帧数、总时长、临时音频和审阅结论。
- 故事板图板和 Animatic 是导演审阅产物，不是后端消费的生产资产；后端仍只消费主题绑定的正式资源。
- `生产总控.md` 是 Gate 3 后唯一的生产状态与进度入口，不在多个流程文件中分别维护项目当前状态。

### 2.4 状态模型

导演母版使用[总控统一状态机](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E5%85%A8%E6%B5%81%E7%A8%8B%E6%80%BB%E6%8E%A7.md#%E7%BB%9F%E4%B8%80%E7%8A%B6%E6%80%81%E6%9C%BA)。方案完整后进入 `review`；内容确认后为 `approved`；Gate 3 通过并成为实现依据后为 `locked`。剧本或实现发生影响性变化而导演母版尚未同步时为 `needs-sync`。

生产总控必须保存：

```yaml
director_owner: <导演负责人>
director_master: <导演分镜母版路径或提交>
director_storyboard_master: <全篇视觉故事板路径或提交>
director_animatic_master: <Animatic 记录路径或提交>
storyboard_coverage_status: pass | fail | needs-audit
animatic_timeline_status: pass | fail | needs-audit
director_review_status: pending | pass | changes-requested | blocked
director_taste_review_status: pending | pass | changes-requested | blocked
director_last_reviewed_at: <时间>
director_next_review: <下一复审节点>
```

## 3. 导演生命周期

```text
锁定剧本
  → 建立覆盖清单
  → 形成导演方案
  → 编制逐镜母版
  → 生成全篇视觉故事板
  → 组装全片 Animatic
  → 校验时长、连续性与可实现性
  → Gate 3 锁定导演母版
  → 监督美术、素材、样片与全片实现
  → 真实音频回填复审
  → Gate 4 平台样片导演审查
  → 全片实现与音频复审
  → Gate 5 发布版复审
```

生命周期分为两段：

- **A 段：导演创作。** 从锁定剧本到 Gate 3，产出可执行的导演母版。
- **B 段：导演监督。** 从 Gate 3 到 Gate 5，持续确认实际实现没有偏离导演母版。

## 4. A 段：形成并锁定导演母版

### A1. 锁定剧本与覆盖关系

先确认剧本路径、版本、状态和确认记录，再建立覆盖清单：

| 剧本 ID | 类型 | 内容摘要 | 必须出现 | 事实／文字约束 | 计划镜头 |
|---|---|---|---|---|---|
| `N01` | 旁白 | 叙事信息 | 是 | 不改变含义 | `S001–S003` |
| `D01` | 对白 | 人物发言 | 是 | 原文／允许微调 | `S004` |
| `B01` | 节拍 | 行动或转折 | 是 | 因果不可丢 | `S005–S006` |

必须满足：

- 每条旁白、对白和关键行动都能映射到镜头；
- 每个镜头都能反查到剧本内容或明确的导演功能；
- 没有镜头时长凭空增加，也没有为了省制作而吞掉叙事节拍；
- 发现脚本问题时写入“剧本反馈”，返回编剧处理，不在分镜里偷偷修正。

### A2. 确立导演方案与视觉语法

导演方案必须先于逐镜表，至少明确：

1. **叙事视角**：观众跟随谁、知道多少、何时改变认知；
2. **景别与机位**：远景交代关系，中景组织行动，近景与特写承载选择、情绪和关键证据；
3. **构图与调度**：主体、视线、空间层次、出入画和注意力转移；
4. **运动与剪辑**：每次推拉摇移、切换或停留的叙事动机；
5. **色彩与光线**：场景区分、情绪曲线和关键转折；
6. **声音策略**：旁白、对白、环境、动作、静默与音乐如何分工；
7. **真实性标识**：年代、器物、神格、地理和来源不确定性如何进入画面；
8. **重复母题与克制规则**：哪些形式可以重复，哪些效果只在关键处使用。
9. **镜内元素系统**：关键元素如何分层、入场、持续、交互、遮挡、退场或循环，以及彼此怎样组成一条可读的事件链。

> [!note] 高品味的定义
> 高品味不是持续运动、堆满细节或频繁切镜，而是清楚、克制、准确。镜头应有明确视点和注意力中心；运动有动机，停顿有压力，细节服务于叙事，形式与神话气质一致。

### A3. 设计逐镜语言

#### 每镜四问

每个镜头必须回答：

1. 观众在这一镜第一次看见或理解了什么？
2. 为什么必须从这个距离、角度和构图观看？
3. 镜头结束时，人物、关系、空间、信息或情绪发生了什么变化？
4. 为什么需要这段时长，而不是更短或更长？

对应的强制字段为：`视觉命题`、`信息增量`、`结束变化`、`时长依据`。任何一项无法填写，通常说明镜头尚未成立。

#### 逐镜表字段

| 字段 | 内容 |
|---|---|
| 镜头 ID | 全片唯一，如 `S001` |
| 剧本绑定 | 旁白／对白／节拍 ID |
| 视觉命题 | 这一镜要让观众看见和感受到什么 |
| 信息增量 | 相对上一镜新增的信息或情绪变化 |
| 时长与依据 | 秒数及其来自台词、动作、观察或停顿的理由 |
| 镜内节拍 | 时间段内发生的有效视听变化 |
| 景别与机位 | 远／中／近／特写，视角与高度 |
| 构图与调度 | 主体位置、空间层次、视线和出入画 |
| 运动与剪辑 | 运镜、主体运动、转场及动机 |
| 表演 | 动作链、反应、停顿和边界 |
| 镜内元素展现 | 关键角色、道具、景物、天气、特效和文字各自如何进入、保持、变化与退出 |
| 交互、遮挡与状态 | 元素间触发／接触／受力、前后遮挡、镜头起止状态及向下镜交接 |
| 声音 | 旁白、对白、环境、动作、音乐和静默 |
| 叙事功能 | 建立／推进／揭示／转折／回响／收束 |
| 结束变化 | 切出前形成的新状态 |
| 资产需求 | 人物、场景、道具、特效和文字；逐项标明静态／动态需求及动作、入出点、持续时间、循环和遮挡约束 |
| 连续性 | 轴线、方向、位置、光线、时间和声音衔接 |
| 证据标识 | 事实来源或改编说明进入画面的方式 |

关键镜头还要写清：

- 镜头焦段感、景深层次和主次关系；
- 起幅、落幅、运动曲线和参数范围；
- 人物动作链、反应链和禁止出现的表演；
- 音效或台词触发点，以及声音先行／画面先行关系；
- 制作人员不能自行猜测的视觉边界。

#### 镜内元素展现表（强制）

导演必须为每个关键镜头建立镜内元素展现表。普通静物可以合并为景层，但凡承担叙事、空间、交互、气氛、遮挡、连续性或注意力功能的元素都必须单列；不得只写“有人、海浪、山、树、雨”等资产名。

| 字段 | 必须回答的问题 |
|---|---|
| 元素／稳定 ID | 具体是什么，是否能追溯到资产需求或文字单元 |
| 叙事功能与注意力级别 | 主体、次要动作、环境连续现象还是只作空间参照 |
| 景深／Z 层与画面区域 | 位于前中后哪层，从哪里出现，会遮住谁或被谁遮住 |
| 起始状态与入场 | 镜头开始时是否已存在；若入场，从何方向、何时、以何种速度／变化进入 |
| 持续行为 | 静止、保持、一次动作、分段变化或连续循环；方向、速度与节奏是什么 |
| 交互与触发 | 与谁接触、碰撞、传递、带动、阻挡或响应；触发前后状态如何改变 |
| 遮挡与可见性 | 何时部分遮挡、完全遮挡、重新出现或硬切消失；不能依赖半透明穿帮 |
| 退场／回落／恢复 | 如何离开、减速、失势、回落、回卷或恢复稳定，而非在动作峰值突然消失 |
| 循环规则 | 是否循环；循环的空间方向、相位、接缝、变体和持续区间；不循环时明确禁止重复 |
| 结束状态与连续性 | 落幅处的位置、姿态、持有物、天气、受力结果和下一镜继承值 |
| 物理／风格边界 | 重力、惯性、阻力、流体方向、接触结果等最低可信规则，以及纸偶／皮影语法允许的抽象程度 |
| 验收证据 | 需要检查的关键帧、完整片段、慢放段或前后镜连续播放 |

镜内元素展现表必须先形成**事件链**，再交给实现。例如：

```text
后层普通浪持续由右向左推进
  → 巨浪从右侧积聚并向左冲岸
  → 前景小浪仍在巨浪前连续经过
  → 巨浪实体遮住女娃并带走她
  → 巨浪失速、回落并向海侧退去
  → 普通浪保持同方向无缝循环
```

不得把事件链压缩成“多层海浪运动”或“女娃被卷走”。实现者不应再替导演猜测元素顺序、方向、层级、遮挡、受力结果或循环方式。

#### 交给镜头素材规划

每镜资产需求必须包含动态素材的动作意图、关键事件、时间边界和遮挡关系；静态镜头也明确登记静态需求。美术与素材阶段据此完成[逐镜素材配置](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E7%BE%8E%E6%9C%AF%E8%AE%BE%E8%AE%A1%E4%B8%8E%E8%B5%84%E4%BA%A7.md#%E9%95%9C%E5%A4%B4%E7%B4%A0%E6%9D%90%E8%A7%84%E5%88%92%E4%B8%8E%E8%BE%93%E5%87%BA)，选择静态图、sprite-gen 精灵动画或后端 rig／三维／程序化资产。导演在分镜阶段给出可验收意图和制作可行性依据，工具与输出契约由素材阶段锁定；不得留到 Blender／Godot 组装阶段再补动作设计。

#### 导演能力完整性审计

逐镜完成后，导演必须检查下列八项能力是否都有可执行答案：

1. **元素清点**：关键可见物、文字、天气和特效没有遗漏，也没有无功能堆叠；
2. **空间调度**：画面区域、景深、尺度、方向和前后遮挡明确，远近环境不是单块拼接；
3. **时间调度**：入场、保持、变化、峰值、恢复和退场有明确顺序与时长；
4. **交互因果**：接触、阻挡、传递、卷走、掉落等动作有触发、反应和结果；
5. **运动可信度**：速度变化、惯性、重力、阻力、流体方向和回落符合镜头所需的最低真实感；风格化可以简化形态，不能破坏因果；
6. **状态连续性**：角色姿态、道具归属、位置方向、天气强度和动作结果能从上一镜进入并交给下一镜；
7. **注意力导演**：同一时刻谁是主焦点、何时转移、哪些环境动作应降级或静止，不让所有元素同时抢戏；
8. **环境系统**：浪、雨、风、烟、群鸟等持续现象具有层级、方向、速度差、相位、无缝循环和变化边界，不以整体晃动冒充源源不断。

任一关键项只能回答“由实现决定”“做一点动效”或“循环即可”，导演母版仍为 `draft`／`review`，不得通过 Gate 3。若动作真实感依赖当前平台不具备的能力，应在 Gate 3 前指定代表样片与降级边界，而不是进入实现后临时删减。

#### 镜内节拍与时长

- 时长由台词、动作、观察、情绪压力和转场需要共同决定，不由“素材能循环多久”决定；
- 超过 6 秒的镜头原则上至少包含两个有效视听节拍；若采用有意静止或观察镜头，必须写明叙事理由与注意力变化；
- 风、雾、颗粒、漂浮、呼吸灯和轻微推拉等环境循环，不算信息增量；
- 重复动作只有在力度、结果、关系或意义逐次变化时才成立；
- 台词时长先按真实朗读或可信语速估算，真实音频回填后必须复核。

#### 空洞内容判定

出现以下任一情况，导演应要求重做，而不是延长循环：

- 主要动作重复，但没有新的信息、阻力、结果或情绪变化；
- 只有环境动效、漂浮物或机械推拉在填充时间；
- 画面只是逐字说明旁白，没有独立的视觉叙事；
- 构图与注意力长时间不变，也没有有意的压力或观察目的；
- 为填满时长随意添加无叙事功能的细节、转场或运动；
- 所有图层同时运动，导致视觉焦点消失；
- 相邻镜头在景别、角度、信息和情绪上都没有推进。

### A4. 生成全篇视觉故事板

文字分镜完成后，导演必须先把全部正式镜号转化为可视化图板，不得只为重点场面生成少量气氛图后直接进入资产或动画制作。

覆盖规则：

- 每个镜头至少一张图板，呈现起幅、主体位置、景别、视线和该镜的核心叙事事件；
- 包含多个镜内节拍、关键交互、遮挡恢复、运镜或复杂转场的镜头，使用 2–4 张或足以覆盖“起幅 → 关键变化 → 动作峰值 → 落幅”的面板；
- 每张图板必须绑定镜头 ID、面板 ID、对应时点／时段、剧本单元、构图说明、动作状态、运镜／转场意图和连续性交接；
- 图板必须覆盖镜内元素展现表的关键事件和状态，不得漏掉角色、道具、环境现象、文字、交互结果或下镜继承值；
- 前后镜必须对账人物位置、动作方向、道具归属、天气强度、光向、轴线和遮挡状态。

故事板允许使用黑白草图、形状块、低保真生成图或其他快速方式。导演对叙事覆盖、构图、镜头语言和连续性负责；绘制或图像生成可以由美术或工具协助。低保真图板不定义最终角色身份、纹理和材质；图像生成造成的身份漂移、多余元素和时代错误不得被默认为后续视觉设定。

### A5. 组装并审阅全片 Animatic

全篇故事板覆盖完整后，按正式镜号顺序和分镜时长组装 Animatic：

1. 使用主题锁定的画幅、帧率和目标总时长；
2. 图板停留、面板切换、临时推拉和转场只表达已登记的镜内节拍，不伪装成已完成动画；
3. 接入临时旁白／对白，并按需添加最低限度的音效、环境或音乐节拍，用于验证音画关系；
4. 检查每条旁白、对白和关键行动均有可见镜头，每个镜头均有信息增量与结束变化；
5. 对账镜号、顺序、单镜时长、总帧数、总时长、事件链和前后镜状态；
6. 连续完整播放审阅全片，对缺镜、重复信息、无效停留、节奏断裂、构图跳变和声画错位逐项返修。

Animatic 不需证明最终材质、高保真表演或平台技术能力，但必须证明全片内容覆盖、镜头结构、时间分配和基础视听叙事已经成立。

### A6. 校验节奏、连续性与可实现性

#### 时长校验

逐镜累加并核对：

- 单镜时长是否有明确依据；
- 每个段落的叙事密度是否合理；
- 高潮、转折、静默和余韵是否获得不同的时间重量；
- 总时长是否等于锁定剧本目标，镜头帧数是否与目标 FPS 对齐。

#### 连续性校验

- 画面：轴线、运动方向、人物位置、道具状态、光线和时间；
- 故事：因果、人物认知、行动结果和情绪递进；
- 声音：环境延续、台词进出、音效触发和音乐段落；
- 视觉语法：景别、色彩、运动和母题的使用是否前后一致。

#### 制作可行性校验

- 每个镜头的资产都可列举，未知项已标记；
- 复杂动作拆成可制作的表演链或明确的降级边界；
- 任何能力限制都不以破坏叙事为代价；
- 可测试的高风险镜头已指定样片或技术验证。
- 关键镜头均有镜内元素展现表，八项导演能力审计没有留给实现端猜测的空项；
- 受力、流体、群体运动、复杂遮挡、无缝循环和状态恢复等高风险行为已指定连续片段验证，不能只看静帧。

### A7. 交付导演母版并通过 Gate 3

Gate 3 前必须完成：

- [ ] 剧本版本为 `locked`，覆盖清单无遗漏；
- [ ] 镜头 ID 全片唯一，逐镜可反查剧本；
- [ ] 视觉语法、重复母题和克制规则明确；
- [ ] 每镜四项强制字段完整；
- [ ] 关键镜头的构图、表演、声音和运动边界足够执行；
- [ ] 关键镜头的镜内元素展现表完整，元素入场、持续、交互、遮挡、退场／恢复、循环和结束状态可执行；
- [ ] 空间调度、时间调度、交互因果、运动可信度、状态连续性、注意力导演与环境系统均已审计；
- [ ] 时长、镜内节拍、总帧数和连续性已校验；
- [ ] 资产需求与高风险验证项明确；
- [ ] 全部正式镜号均有故事板图板，复杂镜头已覆盖起幅、关键变化、动作峰值和落幅；
- [ ] 故事板已通过剧本覆盖、镜内元素、前后镜连续性和多余元素检查；
- [ ] 全片 Animatic 已按正式镜序、帧率和时长完整组装，并使用临时音频完成连续播放审阅；
- [ ] 文字分镜、全篇故事板和 Animatic 的镜号、顺序、时长、事件链和结束状态已对账；
- [ ] 用户已完整审阅并确认导演方案、全篇故事板和 Animatic。

确认后：

1. 文字分镜、全篇视觉故事板和 Animatic 状态从 `approved` 更新为 `locked`；
2. 记录确认时间与确认提交；
3. 在 `生产总控.md` 写入绑定的分镜母版、故事板母版和 Animatic 母版；
4. 后续实现只能基于该母版，变更必须走复审。

## 5. B 段：监督导演母版落地

### B1. 统一监督入口

导演不在各流程文档中追踪“当前做到哪一步”，而是始终读取并更新：

`项目/<主题>/制作/生产总控.md`

每次复审至少记录：

- 审查的产物、版本或提交；
- 审查覆盖的镜头范围；
- `director_review_status`；
- `director_taste_review_status`；
- 偏差、处理意见和负责人；
- `director_last_reviewed_at` 与 `director_next_review`。

### B2. 强制复审节点

| 节点 | 导演检查 | 不通过时 |
|---|---|---|
| 美术与素材方案 | 造型、场景、道具、层级是否支持镜头意图 | 返回美术／素材流程 |
| 平台视觉样片 | 代表性镜头的构图、动作、节奏和风格是否成立；镜内元素事件链、运动可信度、遮挡恢复和环境循环是否按连续片段成立 | Gate 4 保持阻断 |
| 场景数据导入 | 镜头 ID、顺序、时长、节拍和绑定是否一致 | 标记 `needs-sync` |
| 单镜与异常镜头 | 是否出现循环填充、静帧拉长、表演缩水或错误焦点 | 要求逐镜返修 |
| 分段串联 | 转场、连续性、情绪曲线和声音桥是否成立 | 返回相应镜头段 |
| 真实音频回填 | 台词节奏、停顿、触发点和镜头余量是否仍成立 | 重新定时并复审 |
| 全片实现复审 | 导演意图、镜头语言、品味与中文母版是否成立 | `changes-requested`／`blocked` |
| Gate 5 发布版 | 各语言版本和最终导出是否保持同一镜头语义 | 阻止发布 |

### B3. 必须触发导演复审的变更

以下变更不得由实现人员自行视为“技术调整”：

- 增加、删除、拆分、合并或重排镜头；
- 改变单镜时长、镜内节拍或全片节奏；
- 用循环、冻帧、重复动作或无信息动效填充时长；
- 改变动作结果、视线焦点、轴线、景别、构图、运镜或转场；
- 因素材或平台能力而降低表演、叙事或声音设计；
- 真实音频回填后改变镜头入点、出点、停顿或触发关系。
- 实现结果与锁定故事板的关键构图、状态变化或 Animatic 的镜序与时间分配不一致。

变更处理顺序：

1. 实现者在 `生产总控.md` 记录偏差和原因；
2. 导演判断是“忠实实现调整”还是“导演方案变更”；
3. 属于导演方案变更时，先更新导演母版并重新确认；
4. 实现完成后，导演复审实际结果，不只审查文字说明。

### B4. Gate 4 与 Gate 5 通过条件

Gate 4 导演通过必须同时满足：

- 全片镜头顺序、时长与锁定分镜、故事板和 Animatic 一致，或已有批准的变更记录；
- 没有用循环和静帧掩盖内容不足；
- 关键镜头的视觉命题、信息增量、结束变化和时长依据在画面中成立；
- 关键镜头的元素层级、入场、持续、交互、遮挡、退场／恢复、循环与结束状态符合锁定展现表；
- 受力、惯性、流体方向、回落和接触结果达到既定的最低可信规则，注意力接力清楚；
- 表演、构图、运镜、转场和音画关系达到导演标准；
- `director_review_status: pass`；
- `director_taste_review_status: pass`。

Gate 5 前，导演还必须确认最终语言版、字幕、安全框和导出没有改变镜头语义、节奏或观看焦点。导演未通过时，发布闸门保持阻断。

## 7. 导演工作完成定义

导演工作不是在交付分镜时完成，而是在发布版通过 Gate 5 后完成。最终必须能够证明：

- 导演母版绑定了明确的锁定剧本；
- 全部正式镜号均有可追踪的视觉故事板，复杂镜头的关键状态没有缺失；
- 全片 Animatic 已证明内容覆盖、镜序、时长、连续性和基础音画关系；
- 剧本内容、镜头和实现三者可以双向追踪；
- 每个镜头有明确的叙事功能、镜头语言和时长依据；
- 关键镜头内的元素展现、交互因果、最低运动可信度、状态连续性、注意力接力和环境循环均可执行、可验证；
- 生产中的导演复审都记录在固定的 `生产总控.md`；
- 所有影响导演意图的变更都经过复审；
- 最终画面不是靠循环填充，而是靠真实的视听变化承载时间；
- Gate 4 与 Gate 5 均有导演和品味审查的通过记录。
