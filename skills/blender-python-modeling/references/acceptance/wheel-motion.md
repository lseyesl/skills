# 车轮运动验收

先声明轴、半径、目标用途、纯滚动/滑移模式及容差依据。保存侧面和轴向固定视图，至少检查四分之一圈及完整一圈，同时连续播放以识别帧间问题。

- 几何与行为：轮胎/轮毂同心，轮轴中心不绕圈，轴向无异常摆动，胎纹接缝及方向符合设计。不要用外胎花纹的不均匀半径误判轮轴偏心。
- 运动：纯滚动比较路径弧长与 rθ，使用累计、未取模的角度。滑移模式按任务的滑移目标检查，不强制零误差。
- 装配：直行、转向极值、悬挂需要的行程中检查接地、翼子板和制动结构间隙。
- 回归：其他轮子、父级、材质、实例/修改器与目标导出。

正确样例可使用不同局部轴，只要契约明确且运动正确；反例为原点偏移、错误轴、累计转角错误。结构/数值通过不替代实际视觉和目标平台验收。

数值工具：从本 Skill scripts/domain_checks.py 导入 rolling_error(distance, radius, angle, tolerance)。distance 是有符号路径弧长，angle 是沿约定轴的未取模弧度；必须先统一符号，不把往返的绝对路程与净转角相比较。此函数仅检验标量关系，不能证明枢轴或接地正确。
