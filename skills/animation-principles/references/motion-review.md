# 动作审查指南

<a id="poses"></a>

## 姿势可读性、预备与收势

在交付尺寸下看起动、关键接触和结束姿势。观察承重脚、手与道具之间的空隙，以及头和躯干的方向。抬手看起来像垂手时，在源片段里查看邻帧：若手臂离开躯干后剪影更清楚，可选用该帧，并复核其接触状态。原镜头必须保留的遮挡可借助前后运动读懂。

落地显得生硬时，定位触地前、首次接触、重心最低和恢复平衡的时刻，检查脚底与地面、骨盆与膝盖的相对运动。若要表现突然失足，可以直接起动；若要表现主动跃起，则回看蹬地前是否能读出蓄力。

<a id="timing"></a>

## 节奏与帧间距

先记录两个事件之间经过多少秒，再以等时间间隔观察某一点每次移动多远。前者控制动作持续时间，后者显示加速、减速和停顿。关键姿势齐全但播放时仍像匀速滑行，可先核对输出序列是否把不同源帧间隔都播放成相同时长，再决定是否调整插值。保持原帧率复播，留意接触帧是否提前或延后。

**分部位缓入缓出。** 以落地为例，标出首次触地、脚掌承重和骨盆最低的帧。在承重阶段，以地面为基准跟踪实际支点；脚跟滚向前掌时，按支点转移检查。支点应稳住，骨盆仍可下沉，到最低点才减速转向。出现滑脚时先核对支点的位置曲线，再调骨盆的帧间距。复播确认脚底贴地、膝盖缓冲和离地时机。

<a id="paths"></a>

## 运动弧线

在固定视角叠画手腕、脚尖或道具端点的连续位置，标出突然折向的帧。移动镜头先用相邻身体标记区分镜头位移与局部运动。再看折点是否对应碰撞、支点切换或沿导轨运动。无相应原因时，检查该帧的控制器、插值或生成图，修后复核末端落点及抓握关系。

<a id="overlap"></a>

## 跟随与重叠

例如皮影角色急转后停住，标出躯干起动、袖摆转向以及两者停稳的帧。按连接点和材料判断袖摆能否比躯干晚停，刚性护甲可随躯干同步。若袖子像粘住或脱节，先核对肩袖连接，再调整可动段的起止和摆幅。原速回看主动作是否仍清楚，逐帧检查关节搭接。

<a id="staging"></a>

## 镜头焦点与剪影

先用一句话写下这一拍观众应看懂的事件，例如“女孩把信交给老人”。在交付尺寸下原速播放一次，记下第一眼看到谁、何时看清信已换手。再停在接触帧看两只手、信封与躯干之间的空隙。若停帧时看得清，播放时目光却被背景旗子带走，保留递信动作，只把旗子的摆动高峰移出交接时刻；若停帧也分不清交接双方，调整手的剪影或镜头角度。以相同尺寸、速度重播两版，比较观众能否读出交接方向。

**轮廓相切。** 宽袖拂过脸侧时，查看两条轮廓靠近、相切和分开的帧。在成片尺寸下，若袖缘与下颌长时间贴成一条线，试着微调肘位，使两者之间露出空隙，或让袖子明确遮住一小段下颌。保留设计中的拂面接触，连看前后帧确认层次清楚、边缘没有闪跳。

<a id="pose-workflow"></a>

## 关键姿势与逐帧推进

例如角色提灯转身，先摆好起转、重心移到支撑脚、停稳三个关键姿势，锁定手与灯柄的握点。先播放粗略过渡，检查支撑脚是否滑动、灯柄是否脱手。接着沿时间顺序推进灯穗，从起转时的滞后画到停转后的回摆，每一步承接上一帧的方向和速度。若身体节拍有改动，从最早受影响的时刻重看灯穗，连同最后的收势一起复核。使用已有动作库时，用这些事件检查源帧覆盖情况；自由部件按项目的动画制作权限处理。

<a id="secondary-action"></a>

## 次要表演的删减测试

给次要动作写出它传达的意图，例如递信前瞥向门口表示担心被发现。保留递信的手势、镜头和时长，在预览副本里仅关掉这次眼神，按原速回看两版。两版都能读懂交接、只有加回眼神才显得警觉时，保留它；若眼神在交接瞬间把注意力带离信封，先试着提前这一眼，再调幅度。若删掉眼神就看不懂角色在回应谁，应重新确认它是否承担本拍的主要信息。

<a id="volume"></a>

## 跨帧体积与材质形变

在异常帧及其前后各取一帧，按同机位、同时间与源姿势配对。手臂转向镜头时，先核对腕、肘和握点的相对位置，以及源帧里也出现的透视缩短；再沿相同解剖位置比对掌宽、袖口截面与道具搭接。若只有生成帧的手掌突然变窄，回到对应源帧修正该帧，并复播邻帧。遮挡使判断不清时，有三维源可转动视角核对实际厚度；只有单视角时记录能确认的轮廓变化。

按材料决定哪些形变合理。软袖受压可变短、向侧面堆起，松开时检查是否回弹；机械护腕转动时检查两端截面、接缝和握点是否保持设计关系。在 Blender 里若刚性件随弯肘变瘪，检查它受哪些骨骼权重或缩放影响；二维皮影片则重点检查刚性裁片的轮廓和关节搭接。

**主动设计挤压与拉伸。** 对有弹性的软黏土角色，在触地、压缩最深和恢复站稳三处标姿势。以接触面为支点缩短受力方向，按材质向侧面展宽；若起跳需要拉伸，沿运动方向伸长并相应收窄。写下恢复原形的时刻，原速看重量感，再核对接触点、体积和有无意外弹跳。机械护甲或硬质皮影片通过关节折叠表现缓冲，保留刚性部件的截面。

<a id="exaggeration"></a>

## 表演夸张的单变量对照

动作接触正确、意图却读不清时，写下要强调的事件和要保留的情绪。例如女孩悄悄递信，观众需要看见换手，也应感到她在避人耳目。保留原版，在预览副本中只延长交接前的一次停顿；若要尝试改手肘幅度，另从原版制作一版。保持相机、出镜尺寸、播放速度及握点一致。

分别原速看一遍，记录在哪一拍看清换手、动作是否仍显得隐蔽。留下能读清事件且符合情绪的最小调整；原版已经清楚或调整破坏接触时保留原版。仅获准从动作库选帧时，用已有源帧比较取样效果，保持源姿势与对应时长。

<a id="personality"></a>

## 用动作表现角色性格

先写下此刻的行为动机。例如同样提灯探路，谨慎的角色会先试探灯柄，再把灯提稳；急躁的角色可能一把提起，到高处才收住。保持灯的重量、起止位置和握点一致，标记伸手、握实、离桌和停稳四个时刻。按角色意图选择停顿和提速的位置。

用同机位的素模或剪影按原速播放，先隐藏服装和角色标签，记录哪一拍让人读出性格。若只能靠造型区分，选一个节拍调整后重看。复查灯在握实后才离桌，两种表演都能读出同一道具的重量。
