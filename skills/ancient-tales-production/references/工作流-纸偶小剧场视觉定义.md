# 中国神话视频纸偶小剧场视觉定义工作流

本流程是 `visual_profile: paper_theater` 的 `concept_authoring` 入口，负责把锁定分镜转化为纸偶小剧场的视觉契约、角色完整姿态设计、舞台空间规则和代表关键帧。它定义“应该长什么样、能以哪些静态状态出现”，不生成 Remotion 代码、CSS 参数或平台目录。

配置入口：[项目工作流配置](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E9%A1%B9%E7%9B%AE%E9%85%8D%E7%BD%AE.md)。

上游：[美术设计与资产工作流](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E7%BE%8E%E6%9C%AF%E8%AE%BE%E8%AE%A1%E4%B8%8E%E8%B5%84%E4%BA%A7.md)。

下游：[纸偶小剧场静态资产工作流](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E7%BA%B8%E5%81%B6%E5%B0%8F%E5%89%A7%E5%9C%BA%E9%9D%99%E6%80%81%E8%B5%84%E4%BA%A7.md)。

> [!important] 核心原则
> **先用高保真概念母图锁定造型与材质，再从母图拆出纸层并合成静态纸偶；表演由关键完整姿态替换、独立纸片物体和舞台时间轴共同完成。**
>
> 拆件是美术制造步骤：可拆头发、头脸、躯干、前后肢、服装覆片、道具和景物纸层，用于重新合成完整姿态；运行时默认消费已合成的完整姿态，不把这些制造拆件自动升级为骨骼系统，也不生成关节孔、bind pose 或逐帧动画素材。

## 适用范围

以下任务使用本流程：

- 建立纸张、纸板、印刷、剪裁边缘和小剧场舞台的统一视觉语言；
- 设计角色的完整静态姿态、朝向、表情状态与轮廓；
- 设计统一纯色背景幕、独立前中后景纸片、可移动道具和静态特效片；
- 规定舞台深度、角色比例、光影、排版、安全区和连续性；
- 生成并确认能约束后续资产生产的高保真视觉定义。

需要皮影关节、肢体拆件或骨骼动作时，不使用本流程，应重新选择视觉配置并建立新版本。

## 正式输入

- `locked` 的中文母版剧本；
- `locked` 的导演方案／分镜总表；
- 主题级 `主题工作流配置-v<版本>.md`；
- 资料包中的来源特征、D 级创作边界和高风险误读；
- `approved` 的视觉圣经、色彩脚本和资源需求；
- 目标画幅、分辨率、帧率、时长和 locale 集合；
- 主题绑定的 `paper_theater` 视觉配置及版本。

缺少 locked 分镜时只能做风格探索，不能锁定正式姿态集合或资产需求。

## 概念母图硬门槛

纸偶视觉定义不得只由文字、轮廓稿或程序图形锁定。正式资产契约前必须完成：

1. 生成至少一张高保真叙事概念母图，锁定人物身份、服装纹样、色彩、纸张材质、光向和场景气质；
2. 生成同一视觉身份的角色／场景拆件母板，主体互不遮挡、边缘完整、可确定性去背；
3. 建立 `concept_master_id`、源图 SHA-256、提示词版本和区域／对象映射；
4. 记录哪些元素是直接切出，哪些是以母图为高保真参考派生；派生不得改变脸型、比例、服装、纹样和纸材；
5. 只有拆件后重新合成的纸偶预览与概念母图一致，视觉定义才可锁定。

### 可动性驱动的概念图门槛

生成概念母图之前，必须先读取父流程中的场景可动性简报，并为每个需要独立控制的对象建立“镜头需求 → 概念图／状态图 → 可动资产单位”的映射。纸偶路线不要求或允许以骨架图来约束生成；它要求高保真概念图本身就能支持之后的**完整姿态替换、独立纸片位移、视差、遮挡、状态替换和有限整体倾斜／缩放**。

| 对象类别 | 概念图必须预先证明的内容 |
|---|---|
| 人物／动物 | 所需朝向、关键整身姿态、手／足／喙等接触点和会改变轮廓的状态；不可只用一张站姿去要求后端完成全部表演 |
| 植物 | 主茎、叶组、花果中哪些需要整体摆动、弯折、开合、掉落或前景遮挡；需独立运动的部分不能烘焙成背景纹理 |
| 道具／物品 | 完整轮廓、持取／衔取／落点、开合／破损／变形等完整状态；不能只画成手中或场景中的不可分离装饰 |
| 景物／特效 | 山、树、岸、云、浪、火、烟等哪些需要独立景层、视差、遮挡、循环或状态替换；不能用一张整景图掩盖必动对象 |

概念图若把未来要独立移动、替换、遮挡或接触的部分永久遮住，或未提供需要的状态与轮廓，必须先补充高保真视图／状态图或调整镜头构图。不得在静态资产阶段通过临时重画、生成式补全或强行形变挽救；此类概念图判定为不可生产。

代码原生 SVG、CSS 几何和纯轮廓图只能做布局／遮罩诊断，不能成为角色、道具、景物或特效的生产视觉母件。

## 视觉语法

### 纸偶材质与边缘

必须定义：

- 纸张类型、厚度感、纤维、印刷或手绘质感；
- 剪裁边缘、折痕、翘边、背板和投影的允许程度；
- 正面、背面及侧转替换是否需要不同图像；
- 色彩饱和度、黑位、受光面和舞台背景之间的分离规则；
- 禁止出现的塑料感、3D 玩具感、皮影镂空误读和数字贴纸感。

纸张纹理用于建立统一材质，不得掩盖角色身份、来源特征或小尺寸轮廓。

### 场景纸片可读性硬契约

所有由 AI 生成的山、树、岸、云、海浪、石头、建筑和天气片必须在脱离舞台合成后，仍能一眼辨认为单独剪下的纸片。每件场景母件必须同时满足：

- 主要造型由一至三层清楚的平面纸色块构成，不以渐变和写实明暗塑造体积；
- 表面可见轻微纸纤维、压纹或自然色差，但不能用重纹理掩盖轮廓；
- 外轮廓具有轻微不规则的手切边缘、毛边或小缺口，不能像机器切割的光滑矢量贴纸；
- 正面保持二维剪影与平面纸色块，Z 轴只表现统一、有限的纸板厚度，不塑造成圆润连续的实体体积；
- 至少一侧在 3/4 透视下清楚显示可见切边和统一纸厚，不能只有正面轮廓或靠投影假装厚度；
- 内部造型以两层或以上彼此平行的纸片叠合，层与层之间保留可读的搭接、边缘或轻微高度差；
- 母件自身不烘焙场景方向投影，进入目标平台后由统一舞台投影预设处理；
- 除纯色底幕外只包含一个可独立摆放的主体，使用透明背景或可确定性去除的批准色键背景。

以下任一情况均判为纸片材质失败：普通插画只叠纸纹滤镜、完全无 Z 轴厚度的二维剪影、只有投影而没有可见切边、各层厚度漂移、塑料贴纸感、过度光滑矢量边、油画或摄影式光影、圆润连续体积的 3D 玩具／黏土质感、完整风景构图、全画幅背景矩形，或必须依赖 Remotion 滤镜后才看起来像纸。

每个主题必须先建立 `paper_material_profile` 和纸片材质校准板。校准板至少同时放置山体、植被、岸线、海浪和天气片各一件，记录纸张类型、固定色板、边缘、纸芯、纹理、投影边界和提示词版本；校准板未通过时不得批量生成正式场景包。

### 舞台与镜头

纸偶小剧场默认使用有限深度的二维舞台：

- 背景幕只提供统一底色与主光色，默认使用白／暖白或黑／近黑，不绘制山海、建筑、天气或其他完整场景细节；
- 中景片承担建筑、山体、树木、岸线、云片、水浪和主要遮挡，每件都必须能作为独立纸片进入舞台；
- 前景片承担框景、近景遮挡和舞台边缘；
- 角色与可移动道具位于明确景层，不依赖真实三维体积；
- 镜头通过推拉、平移、轻微旋转、视差和裁切制造动态；
- 拉幕、换景、翻页、抽拉、升降和纸片覆盖可以成为风格化转场。

天气以舞台底幕明暗和少量独立纸片表达：普通、晴朗或叙述段使用白／暖白底幕；风暴、危险或压迫段使用黑／近黑底幕，并按需增加云片、雨线、闪电或风向纸片。不得为天气另做一张详细背景图。

每个主题必须在视觉定义中记录允许的舞台动作和禁用动作。不得为了增加动态而在逐镜阶段临时改成肢体关节动画。

## 角色完整姿态定义

### 姿态来源

姿态集合只从 locked 分镜的实际表演需求推导。每个姿态必须服务至少一个镜号、动作节拍或连续性状态；不得为了“以后可能需要”无限生成姿态。

单个角色定义至少记录：

| 字段 | 内容 |
|---|---|
| 角色稳定 ID | 跨视觉定义、资产清单和实现记录使用 |
| 来源特征 | A／B 级特征与可信边界 |
| D 级设定 | 服饰、纹样、表情和造型推演 |
| 身份不变量 | 轮廓、比例、色彩、冠饰、武器和物种特征 |
| 允许朝向 | 正面、侧面、三分之二或背面中的实际需要 |
| 完整姿态 | 中立、行进、举物、倒下等分镜要求的整身状态 |
| 表情状态 | 只在目标画幅可读且剧情需要时建立 |
| 接触意图 | 脚底、座位、手持物和另一角色的视觉接触位置 |
| 舞台动作 | 整体位移、缩放、倾斜、浮动、震动或姿态替换 |
| 禁止项 | 不允许拆分、变形或漂移的部分 |
| 对应镜号 | 使用该姿态的全部镜号 |

### 完整静态边界

- 每个角色姿态是一个完整轮廓，不拆成头、躯干和四肢；
- 角色需要明显动作变化时使用另一个完整姿态，不在 Remotion 中弯曲肢体；
- 表情差异如果小尺寸不可读，不单独生成；
- 手持道具只有需要独立显隐或跨角色复用时才分成独立完整道具；
- 同一角色的所有姿态必须保持身份、比例、材质、服饰和色彩连续。

### 关键完整姿态集

每个主要角色可以根据 locked 分镜建立少量关键完整姿态。姿态集不是逐帧动画，而是一组能够在目标画幅中清楚区分动作阶段的整身静态母件。

姿态集至少记录：

| 字段 | 内容 |
|---|---|
| `pose_set_id` | 同一角色姿态包的稳定 ID |
| `pose_id` | 单个完整姿态的稳定 ID |
| 动作阶段 | 例如中立、预备、发力、腾空、落下、滑翔、振翅上扬、振翅下压 |
| 替换节拍 | 哪些镜号、动作节拍或连续段允许切换到该姿态 |
| 对齐意图 | 姿态替换时角色视觉中心、脚底、喙部或持物接触应保持的连续关系；不写平台 pivot 坐标 |
| 搭配整体运动 | 水平移动、升降、上下浮动、俯仰、轻微旋转、缩放或震动中的允许组合 |
| 最短保持 | 姿态应至少保持到可读，不允许无意义逐帧闪烁 |

飞鸟不得只靠水平平移表现飞翔。飞行姿态集原则上应包含滑翔、振翅上扬和振翅下压，关键剧情状态再增加衔石、衔枝或投下后的完整姿态；时间轴同时提供可读的上下浮动、轻微俯仰和飞行弧线。人物行走、受风、倒下或下沉也可用少量关键整身姿态替换表达。

## 场景、道具、特效与排版

### 场景景层

每个正式场景定义：

- 舞台总览与目标画幅；
- 纯色底幕、独立前景／中景物体和必要环境纸片的视觉职责；
- 各景层的遮挡边界、透视关系、光向和安全移动范围；
- 可以整体移动或替换的景层；
- 不得在平台中重新解释的构图与连续性约束。

纸偶路线默认不制作含完整景物细节的整张场景背景。背景幕保持统一纯色；所有需要被观众识别的山、树、岸、云、石头、建筑和水体边界均作为独立完整舞台物体。即使物体本身不运动，只要承担构图、遮挡或空间识别，也必须独立于底幕。

海面是强制分层对象：至少使用三排独立海浪纸片形成后浪、中浪和前浪；各排必须具有不同 Z 层、遮挡关系、水平偏移或运动相位。不得用一张大海图片、单个矩形渐变或单排波形替代多排海浪。

### 道具与状态

道具按完整状态交付，例如“完好”“破损”“点燃”“石块已放下”。状态变化用完整替换表达，不建立机械结构或抓取骨骼。

### 特效

优先把火、云、水、烟、光晕等定义为视觉目标和运动意图。只有确需纸片质感时才生成静态遮罩／纹理；程序化重复、粒子和时间变化由 Remotion 实现流程决定。

### 排版

文字资产记录稳定文本单元 ID、字体、字号层级、版式、安全区、来源标识和 locale 规则。除不可替代的书法图形外，不把可本地化文字烘焙进背景或角色图。

## AI 生成与一致性约束

- 以已确认主视图、材质板和身份不变量作为后续姿态生成约束；
- 所有 AI 生成的角色完整姿态、场景物体、海浪、道具和纸片特效都必须继承同一个 `paper_material_profile` 与材质母句，不得按资产类别临时改换纸张厚度、边缘或层叠语言；
- 正向材质母句必须逐字包含 `2.5D cardstock puppet, flat rigid pieces, uniform paper thickness, visible cut edges, layered construction, 3/4 perspective`，并继续包含 `isolated handmade matte cardstock paper cutout`、`flat layered color shapes`、`subtle visible paper fibers`、`slightly irregular hand-cut edge`、`thin pale paper-core rim`、`no baked cast shadow` 和 `single object only`；
- 场景物体的负向约束至少包含 `no landscape`、`no character`、`no text`、`no frame`、`no photorealism`、`no fully volumetric 3D render`、`no rounded solid volume`、`no plastic sticker` 和 `no full-frame background`；生成角色时移除 `no character`，但不得删除其他材质与 2.5D 结构约束；
- 海浪只描述为“一整排横向海浪纸片”，不得使用会诱导完整大海构图的 ocean、seascape 或 cinematic ocean background；
- 每次生成必须绑定资产 ID、对应镜号、视觉定义版本、`paper_material_profile` 和提示词版本；角色姿态另绑定角色 ID、`pose_set_id` 与 `pose_id`；
- 每次生成还必须绑定场景可动性简报条目和概念图覆盖状态；若该对象有登记的独立运动、接触、遮挡或状态替换需求而概念图未覆盖，停止生成并退回本流程补图；
- 可以生成完整姿态候选板，但正式资产必须从被确认候选确定性导出；
- 不允许用低保真火柴人、关节线、骨架图或皮影拆件板作为默认生成输入；
- 不得在后端逐镜阶段重新生成“相似角色”补洞；
- 生成结果出现脸型、冠饰、服饰、比例、物种或纸张材质漂移时，退回本流程建立新候选。

## 审阅与锁定

按“视觉系统 → 角色定义包 → 场景／道具定义包”审阅，不要求逐张图片建立人工节点。一个定义包只有在内部项目一致、对应镜号完整且权利状态清楚时才进入用户审阅。

用户确认单个定义包后：

1. 写入确认日期、确认者、版本、状态和禁止漂移项；
2. 核对来源／D 级边界、对应镜号和权利状态；
3. 按总控协议纳入当前视觉定义阶段的精确里程碑提交；同批定义包不逐图提交；
4. 将该具体版本设为 `locked`，交给静态资产流程。

上游分镜或身份不变量发生影响性变化时，相关定义包标为 `needs-sync`，不得覆盖旧版本。
