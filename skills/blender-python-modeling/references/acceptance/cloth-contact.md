# 布料接触与缓存验收

1. 分别确认布料对象碰撞、自碰撞需求、碰撞体 Collision 与集合、pin、起始几何和尺度。

2. 连续采样接触开始、快速运动、最差接触与结束；同时看穿透、悬浮、抖动和 pin 泄漏，容差随资产尺度声明。

3. 冻结输入/参数后烘焙到任务拥有路径，重开文件验证缓存；修改上游后不得复用旧通过回执。

4. 正确样例：短布片接触简化碰撞体；缺陷：未启用 Collision、初始穿插、过大距离导致悬浮；替代：远景旗帜允许不启用自碰撞，近景衣物按需要启用。

5. 配置预检和短模拟只认证对应范围，不认证任意人物服装或最终渲染。

来源与采用边界见 [制作来源](../sources/production-sources.md)。
