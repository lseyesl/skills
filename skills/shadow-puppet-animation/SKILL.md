# 皮影动画制作

先让动作有原因、接触有依据、轮廓能读懂，再增加纹饰、环境运动和镜头效果。产物必须是可复查的实际资产与镜头，不能用提示词、骨骼数量或渲染成功代替视觉和动态验收。

## 边界与协作

本技能负责皮影动画的视觉、运动和导演实施规则，不是渲染引擎或影片总控。

- 新角色概念调用 [shadow-puppet-image](../shadow-puppet-image/SKILL.md)；独立部件、坐标、绑定和活动范围调用 [shadow-puppet-part-splitter](../shadow-puppet-part-splitter/SKILL.md)。不重复实现其工具或改写原生 manifest。
- Blender 场景、相机与渲染按需调用 [blender-python-modeling](../blender-python-modeling/SKILL.md)；其他后端先核对实际支持的层序、锚点、约束和导出能力。不可用时明确停在哪个阶段。
- 正式神话制作项目沿用 [ancient-tales-production](../ancient-tales-production/SKILL.md) 的上游、隐藏区策略与批准事实；独立镜头不额外制造 Gate。项目后端承担整片装配。
- 可选协作不自动安装。执行前确认选中能力可用；库动作只有匹配角色、接触和事件要求才使用，不能把普通走路套成挑担、推车或挥棒。
- 新媒体和制作记录放在当前任务／项目输出目录。本技能内的参考证据只供分析，不直接作为新片生产资产；不把用户素材上传公共服务。

## 1. 接收任务并选定可验收目标

读取已有项目、最新分镜、资产状态、风格与用户授权，保留既有修改。能够从参考或上下文确定的内容自行推进，不为常规专业选择反复询问。

记录：故事与受众、交付范围、画幅／fps／音频、参考版本、输出位置、可用生成与动画工具、禁止改动项。未指定时沿用项目规格；新项目先用目标画幅做短样片，技术参数不冒充原片参数。

将“参考品质”拆成六项：造型与纹样、可动连接、动作与接触、场景与镜头、叙事与声音、全片一致性。每项选择参考时间码、可观察目标和验证方式。明确借鉴哪部片的哪些特征，不要求同时复制两部片的全部外观与叙事。

优先原速观看；工具只能抽帧时记录间隔、时间范围和盲区。抽帧只能支持画面及采样姿态判断，不能批准流畅度、落足、同步或精确节奏。没有原片时可用本技能证据设计，不能声称重新看过原片。

## 2. 分镜先于资产批量生成

每镜写清：开始状态 → 触发原因 → 行动 → 接触／关键事件 → 结果 → 下一镜继承状态。先验证无台词时观众能否读懂关键事件，再安排对白、字卡与音效。

选能暴露风险的代表镜头：常规全身行动、近景表演、多角色／道具接触；有打斗、变身、波浪或长衣时增加对应高风险镜头。先完成这些样片，再批量扩展。数量按内容决定，不以简单空镜替代复杂动作验证。

## 3. 建立统一视觉和资产契约

按资产设计参考确定角色身份锚点、服装结构、线条与镂空密度、场景层级、道具比例、光色和材质规则。先做角色—道具—背景同框测试，再批准风格扩展。

每个活动对象说明：谁控制它、绕哪点动、接触谁、被谁遮挡、运动暴露什么、允许范围是什么。运动父子关系与绘制层序分开。服装不能替代身体支撑结构，装饰不能掩盖断肢；手、袖与道具交叉时按需细分绘制片。

生成遵循“概念／状态图 → 目视修正 → 可控分层资产 → 原姿态回组 → 目标姿态试动”。仅有整图、拆件拼版或背景被烘焙的图片时，不能报告已得到可动画组件。受保护的脸、花纹及连接区变化须检查。

## 4. 先验证运动逻辑，再细化表演

按动作参考建立接触状态和事件表，声明局部肢体运动、根节点路径、道具运动、环境运动与相机运动分别由谁负责，防止重复位移。

- 走路先定路径、支撑脚与步幅；持物先定抓握／承托；跳跃先定起跳、空中路径与落点。
- 冲击先定攻击目标、命中／闪避时刻和结果；回避动作也必须与攻击轨迹相容。
- 神话飞行可违背现实重力，但要有一致规则、意图和可追踪路径。
- 变身、换装与转向显式管理身份、姿态、道具和遮挡，不依赖随机重生成补过渡。
- 动作以清晰关键姿态和必要停顿组织，附属摆动稍后加入；不把所有关节都接到连续正弦摆动。

从灰模／简化片件到正式纹理逐步验证。换正式资产后复查相同动作，不把代理资产通过当成最终资产通过。

## 5. 场景、镜头、声音与合成

在正式镜头内复核轮廓、视线、活动区域、遮挡、水线／地面和字幕安全区。二维舞台感不排斥层次与景别变化；相机运动必须帮助说明行动或关系。

环境运动应与主表演分配注意力；雨、花瓣、烟火、波浪须有源头、方向、遮挡和消失规则。物理模拟仅在风格和控制需求允许时选用，不默认以写实水体替换装饰波纹。

声音按叙事事件安排，检查脚步、落地、碰撞、对白和字卡阅读；没有听音条件时明确标记音频未审。输出后检查分辨率、fps、时长、色彩、音轨、帧缺失及资产打包。

## 6. 对照验收、修复与交付

按质量参考分别做全尺寸静帧、原速连续、接触逐帧、跨镜连续性检查。参考和产物采用可比的画幅、景别与显示尺度。记录通过／失败／未验证；技术检查不自动变成专业批准。

结构断裂、关键接触失效、因果不成立、角色漂移不能被高美术分抵消。导演先修锚点、层序、动作、镜头等授权范围内问题；仍无法解决则记录时间码、影响、尝试、备选和复审方式，随成片汇总。用户已授权集中审阅时不为一般制作问题中断；无法继续的权限或必要输入才报告阻碍，不编造批准。

交付实际产物、引用版本、可编辑源、资产原生 manifest、镜头／事件映射、参考对照、QA 和遗留问题。概念、可动资产、样片、全片分别声明完成范围。“达到参考品质”只在对应目标及全范围原速／视觉／音频审阅都有证据时作有范围的结论；本技能本身不提供这种保证。
