# 生成/扫描网格恢复为可交付资产

适用：生成、扫描、雕刻得到的高密或不整洁网格。先读 [通用建模](../../modeling-recipes.md)；来源依据见 [来源表](../../sources/production-sources.md) blender-remesh / retopoflow。新规范为 experimental。

## 分析与输入

记录用途（静态近景/远景、可变形角色、实时道具、打印）、单位、目标镜头/屏幕尺寸、预算、活动区域、原网格与贴图哈希。保留源高模作为轮廓与烘焙依据。枚举形态键、权重、UV、颜色属性、材质和实例依赖；不能只看面数就处理。

用 [制作诊断工具](../../../scripts/production_checks.py) 的 mesh 模式读取求值网格与基础拓扑，结合线框/侧面/内部视图区分意图和缺陷。开放衣片、眼口结构和薄片不因边界边存在而自动判坏。闭合要求由目标决定。

| 事实/目标 | 路径 | 禁止推断 |
|---|---|---|
| 静态远景，现状满足运行预算 | 保留或只删明确的无用几何 | 不为“看起来整齐”默认重拓扑 |
| 静态实时道具，拓扑不承担形变 | 在派生副本尝试减面，保留轮廓/开孔/材质边界 | 面数更少不等于性能一定改善 |
| 雕刻体需要体积融合/表面重建 | 评估 Voxel；按最小需保留厚度试验分辨率 | 不宣称保留 UV、薄片和锐边 |
| 角色需关节形变 | 按弯曲和轮廓手工控制边流，可选投射辅助 | 全四边面或 QuadriFlow 成功不等于绑定就绪 |
| 封闭打印实体 | 检查闭合、自交、尺度与最小厚度后局部修复 | 不自动填掉眼口/装配孔等设计结构 |

## 处理

1. 在任务拥有的副本做一个代表性区域，先保留源高模和静止几何基线。
2. 去重阈值、薄壁和清理范围来自单位与最小特征尺寸；先定位，再合并/填补。不得全局随意 merge-by-distance。
3. 比较候选的轮廓、孔洞、接触位置及特征；拓扑变化后转入 [数据迁移](data-transfer-repair.md)。高低模烘焙转入 [法线/烘焙诊断](../surfacing/normal-bake-repair.md)。
4. 每次改动按 [网格恢复验收](../../acceptance/mesh-recovery.md) 检查；角色再运行目标姿势，实时资产再测消费端预算。

若局部特征消失或依赖数据无法可靠迁移，回滚候选，缩小范围或换路线；不降低目标，也不覆盖唯一源文件。报告保留/推断/舍弃的结构与未验证项。
