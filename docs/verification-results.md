## 发现并修复

1. 添加骨架查询的通用契约排在具体处理流程前面：补充术语，得分相同时优先 procedure。
2. React wheel event 误命中车轮，以及 Blender 启动崩溃误命中建模：增加可解释的查询排除条件。仍不宣称理解任意复杂意图。
3. null 现场信息误当成已知事实：空值保持未知；条件值类型需一致。
4. 总任务都失败时，已通过子检查退化可能被掩盖：比较器现在报告 check_regressions，不以总失败状态掩盖保留能力的丢失。
5. 实机默认降噪器在当前构建缺失：第一次修复实验退出失败；关闭可选降噪并完整重跑成功，没有将第一次失败算通过。

独立 8 项探测（7 条查询及 1 条未知信息检查）最初 4/8 通过，修复后 8/8；只证明这些已知问题的修复，不是泛化成功率收益。

车轮旋转中心最大位移由 0.4999999702 降为 1.0081e-7（场景单位），静止网格世界坐标变化低于 1e-6。指段第 107 顶点的缺失权重被检测并修复，基础 deform 数值检查通过；近端环表面位移低于 1e-6、远端发生预期运动，非目标立方体数据未变。
