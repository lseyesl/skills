# 车轮偏心、摆动与滚动诊断

适用：已有车轮在旋转/转向/行驶中异常。记录真实运动轴、枢轴层级、对象变换、约束、半径和接地模式；纯滚动、打滑、静态转台分开验收。

| 区分检查 | 原因 | 处理 |
|---|---|---|
| 关闭动画，在副本沿预期局部轴转一周，中心仍绕圈 | 原点/几何不同心 | 用截面及轮轴标记校正；保持组件世界位置，不随意移动整车 |
| 中心稳定但侧面摆动 | 旋转轴、父级变换或约束 | 检查局部轴与非均匀缩放；拆解测试约束关系后恢复 |
| 单独正常，组合转向时异常 | 转向/滚动层级混淆 | 独立转向枢轴与滚动子对象，检查约束空间 |
| 转动稳定，前进时滑动 | 转角、有效半径、根运动不匹配 | 纯滚动按路径弧长配置角度，明确符号与单位；打滑保留设计意图 |

纯滚动使用累计距离 s 与累计转角 θ：s≈rθ（弧度），曲线路径用弧长而非两端直线距离。按目标尺度确定允许误差。对滑移、轮胎变形或镜头作弊不要硬套此式。按 [运动验收](../../acceptance/wheel-motion.md) 测试，并复查原材质、实例和导出关系。失败回到轴/枢轴/层级诊断，不用更多关键帧掩盖根因。
