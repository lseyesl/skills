# 手部姿势验收

修改前按目标风格和尺度声明姿势、容差与严重缺陷；同一相机/材质/灯光比较前后，保存原文件和姿势。静态交付可标记动态项不适用，但不得宣称可动画。

- 结构：目标 mesh/armature、指部权重和动作关联存在，原有非目标内容未变；运行领域检查脚本的 weights 模式作数值诊断。
- 行为：逐指弯曲、张手、握拳、拇指对掌、腕部扭转及用户指定姿势；运动范围来自任务，不硬套人体极限。
- 视觉：掌侧、掌背、侧面与三分之四视角检查关节体积、指缝、穿插、轮廓和纹理。检查实际求值网格及最终显示距离，不只看骨架。
- 回归：原动作、形态键组合、对侧手和需要的导出能力。

正确样例应在全部请求姿势保持允许范围；反例包括权重和为 1 但跨指污染、骨轴侧摆、静态正确但握拳塌陷。合法风格化的夸张手指不能仅因不符合写实比例失败。所有必需检查通过才认证该范围；未执行的视觉项必须 unknown。

数值工具调用（隔离副本）：`blender <copy.blend> --background --python <skill-dir>/scripts/domain_checks.py -- --object <mesh-name> --limit <platform-limit>`。经 MCP 可导入 inspect_weights；参数来自交付目标。该工具不自动修复权重。
