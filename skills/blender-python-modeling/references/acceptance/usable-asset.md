# 从图片模型到可用资产的分级验收

先声明用途、平台、尺度依据、视图、交付范围、预算和运行环境；没有统一的“可用模型”门槛。源图看不见的深度是推断，不得称测量真值。

| 交付级别 | 必需检查 | 不足以通过的证据 |
|---|---|---|
| 可编辑静态资产 | 所需外观/内部结构、可编辑源文件、求值预算、材料/纹理和对象范围；隔离重载 | 好看的单张截图、文件存在、纯外壳或轮廓相似 |
| 可动机械资产 | 上述检查；明确枢轴/父级、实际运动、装配间隙及所需导出 clip | 零角度下轮轴静止、对象已 parent、只检查动作数量 |
| 可绑定角色 | 合适静止姿态/拓扑、持久骨架和权重、实际关节形变、目标预算 | 自动权重完成、骨头存在、临时两骨探针成功 |
| 动画交付角色 | 前一级；声明动作及范围、源与重载后的 skin/clip/实际形变、必要时接触/循环及原速审阅 | 静态角色导出正常、单姿势正常、只看蒙皮权重和 |

源 `.blend` 正常打开就应进入正确任务场景。交付 GLB 对象白名单必须排除默认 Cube、旧场景选中对象、参考图和渲染灯光，除非契约明确要求。骨骼显示辅助与资产网格要依据实际引用区分。

静态导出对照准备好的求值网格；有意减面必须独立声明，并在匹配相机/灯光/尺度下复核轮廓、局部和材质。无法解释的三角面或包围盒变化判失败，不因格式合法而放行。有动画时还要检查对应帧表面、骨层级与 clip，shape keys/约束/驱动需要专门验收。

评分分别保留外观、结构、用途、过程与实际成本。任一必需用途失败即未通过，不能让其他高分抵消。降低面数但丢失脸型、蒙皮或动作属于回归；仅在已声明允许的用途取舍中报告条件性收益。

完整最终声明仍使用模块台账及视觉对照；本验收不取代 [角色验收](character-export.md)、[车轮验收](wheel-motion.md) 或 [GLB 验收](gltf-delivery.md)。未测项目、目标引擎或实际模型身份保持未知；不能由技术合成夹具推断真实 Agent 提升。
