# 角色绑定、蒙皮与导出

适用：可变形角色新绑定、权重修复或骨骼动画导出；静态雕塑不自动进入此流程。先读 [角色交付](../../character-delivery.md)。

1. 检查实际网格、现有骨架/形态键/动作、尺度、静止姿态、关节体积与拓扑。已有兼容绑定只修必要部分，不能因工具预设不同而重绑。
2. 如静止网格无法支撑运动，保留源资产，准备派生变形网格；如骨架轴/层级不合理，先改骨架并评估已有动画依赖，最后再做权重。
3. 新骨架根据关节标记放置骨骼与弯曲方向，区分变形/控制骨，确定根运动和目标引擎。自动权重仅是初值；检查未赋权、非单位和、跨肢体影响、超平台影响数与不存在的骨组。
4. 数值异常先局部清理；数值正确但视觉异常时检查骨轴、拓扑、修改器顺序和蒙皮方法，不重复归一化来碰运气。控制组/遮罩组不参与 deform 归一化。
5. 按请求验证基础 FK、完整活动范围或行走接触。只做小幅 FK 不得标为 locomotion validated；行走需要完整周期、实际足底、支撑/摆动和循环接缝。
6. 仅在交付边界建立导出副本，按目标烘焙约束/驱动，保留源骨架和动作。导出后在隔离场景或目标引擎重新载入，比较静止姿态、关键动作、形态键和材质。

失败时区分源场景问题与导出变换/采样问题；源正常而导出异常优先检查导出副本、轴、采样和动作筛选。按 [角色导出验收](../../acceptance/character-export.md) 检查；未知平台能力保持未验证。
