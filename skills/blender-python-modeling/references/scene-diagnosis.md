# 场景诊断

1. 按主 Skill 检查连接、Blender 版本、场景清单；读取目标对象、模式、单位、变换、修改器、约束、骨架、顶点组、形态键、动作及资源路径。
2. 通过 owner/稳定 ID 和关联关系定位，名字只作辅助。多个同名/相似对象时先消除歧义；禁止猜一个后全场景替换。
3. 复现用户问题：固定相机、帧、材质、灯光与修改器状态，保存基线。区分静止网格、求值后形变、动画控制与导出后的问题。
4. 对每个假设执行最小区分检查，例如临时禁用任务对象的 Armature 来区分静止形态与变形问题；在副本操作，记录并恢复开关、姿势与可见性。
5. 记录检查结果和原因置信度。未知保持未知；不能看到症状就决定重建。先修复上游原因，再检查下游表现。

修改完成后检查原对象/骨架/动作/材质关联以及未授权对象签名，重复同一复现步骤。使用 [方案选择](procedure-selection.md) 进入处理路径。
