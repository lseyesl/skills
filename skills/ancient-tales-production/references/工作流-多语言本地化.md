# 中国神话视频多语言本地化工作流

本流程把锁定的中文内容母版转化为一个或多个可配音、可排字幕、可追踪的语言版本。它管理文本单元、术语、翻译、屏幕文字、字幕和语言时间轴，不负责生成或混合真实音频。

上游流程：[编剧工作流](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E7%BC%96%E5%89%A7.md)、锁定导演时间结构与项目当前视频母版接口。

下游流程：[音频交付与导入工作流](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E9%9F%B3%E9%A2%91%E4%BA%A4%E4%BB%98%E4%B8%8E%E5%AF%BC%E5%85%A5.md)。

> [!important] 核心原则
> **中文是内容权威，不是所有语言的时长模板。文本单元 ID 和语义保持稳定，每种语言独立形成自然表达与时间轴。**

## 适用范围

- 为中文母版建立可追踪的旁白、对白和屏幕文字单元；
- 生成 `zh-CN`、`en-US` 或其他 BCP 47 locale 的本地化稿；
- 管理神名、地名、古籍名、称谓和改编标识；
- 为每种语言准备配音台本、字幕 JSON、SRT 和 VTT；
- 根据语言朗读时长建立镜头时间覆盖；
- 处理译文变更及其对音频、字幕和视频的影响。

## 正式输入

- `locked` 中文母版剧本；
- `locked` 导演方案和稳定镜号；
- `locked` 视频实现母版或至少稳定的场景边界；
- 中文事实标识、古籍原文、来源署名和改编标识；
- 目标语言清单、受众地区、语气、年龄层和平台规格。

视频实现尚未锁定时，可以翻译和术语审阅，但语言时间轴只能标为 `draft`。

## 默认目录

```text
项目/<主题>/制作/本地化/
├── language-manifest-v1.yaml
├── 术语表-v1.md
├── 文本单元表-v1.md
├── zh-CN/
│   ├── 本地化台本-v1.md
│   ├── timeline-v1.json
│   ├── captions-v1.json
│   ├── subtitles-v1.srt
│   └── subtitles-v1.vtt
└── en-US/
    ├── 本地化台本-v1.md
    ├── timeline-v1.json
    ├── captions-v1.json
    ├── subtitles-v1.srt
    └── subtitles-v1.vtt
```

新增语言时增加 locale 子目录，不复制整套中文项目文件。

## 状态协议

每个 locale 独立使用[总控统一状态机](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E5%85%A8%E6%B5%81%E7%A8%8B%E6%80%BB%E6%8E%A7.md#%E7%BB%9F%E4%B8%80%E7%8A%B6%E6%80%81%E6%9C%BA)。文本、术语和字幕齐全后进入 `review`；语言内容确认后为 `approved`；成为具体音频或终片输入后为 `locked`。一个 locale 的状态不会改变其他 locale；中文母版、镜号或视频版本发生影响性变化时，对应 locale 为 `needs-sync`。

## 一、建立语言清单

`language-manifest-v1.yaml` 至少记录：

```yaml
topic: <主题>
version: v1
content_master_locale: zh-CN
script: "[[<锁定中文剧本>]]"
video_master: "[[<锁定视频实现记录>]]"
locales:
  zh-CN:
    status: draft
    timeline_version:
    audio_version:
    final_version:
  en-US:
    status: draft
    timeline_version:
    audio_version:
    final_version:
```

locale 使用明确的 BCP 47 标签，如 `zh-CN`、`en-US`、`ja-JP`；不能只写“中文”“英文”而省略地区和语言变体。

## 二、建立稳定文本单元

中文剧本中的可说、可显示文本必须映射到稳定 ID：

| 类型 | ID 示例 | 内容 |
|---|---|---|
| 旁白 | `YW-01-N01` | 对应镜头内第 1 条旁白 |
| 对白 | `JT-08-D01` | 对应镜头内第 1 条对白 |
| 标题 | `YW-05-T01` | 标题、章节名或转场字卡 |
| 事实标识 | `YW-01-F01` | 原典、来源、研究归属或改编提示 |

规则：

- ID 由稳定镜号、类型和序号组成，不随语言翻译；
- 一条语义一个 ID，不把整段旁白塞进单个不可分割单元；
- 中文修改语义时建立新文本版本，并检查所有 locale；
- 仅调整断句或字幕分页时，不更换文本 ID；
- 已配音后禁止复用旧 ID 表示不同语义；
- 跨镜延续的同一句可保留一个文本 ID，但时间轴必须记录覆盖镜号。

对于已有剧本，不为了补 ID 覆盖锁定版本。建立 `文本单元表` 作为映射；下一版剧本再原生加入 ID。

## 三、术语与文化边界

术语表至少包括：

| 中文 | 类型 | 目标语言 | 首选形式 | 禁用形式 | 首次解释 | 依据／理由 |
|---|---|---|---|---|---|---|
| 精卫 | 神话角色 | en-US | Jingwei | <错误形式> | 是／否 | 来源与受众判断 |

重点检查：

- 人名、神名、地名和古籍名是否音译、意译或保留汉字；
- 亲属称谓、身份等级和情绪强度是否准确；
- A／B／C／D 证据层在译文中没有被抹平；
- “古籍记载”“后世说法”“研究者认为”“本片改编”仍清楚可辨；
- 古籍原文与现代释义分层显示，不用流畅译文冒充原文直译；
- 同一术语在配音、屏幕文字、字幕和交付说明中一致。

## 四、本地化台本

每个 locale 的台本以文本单元为行：

| text_id | scene_id | speaker | zh-CN 母版 | 本地化文本 | 发音／表演注 | 屏幕／口播 | 状态 |
|---|---|---|---|---|---|---|---|
| YW-01-N01 | YW-01 | narrator | … | … | 神名读法；克制 | 口播＋字幕 | draft |

本地化不是逐字替换。允许调整语序、拆合句和自然停顿，但必须：

- 保持事实、人物关系、因果、情绪方向和改编边界；
- 不擅自增加中文母版没有的解释或结论；
- 不删除来源、原典或改编标识；
- 与文本单元一一可追踪；拆分时使用子 ID，如 `YW-01-N01a`；
- 为配音提供数字、专名、古文和情绪的发音／表演备注。

## 五、各语言独立时间轴

每个 locale 单独测读或使用最终配音时长，生成 `timeline-v1.json`：

```json
{
  "locale": "en-US",
  "fps": 30,
  "videoMasterVersion": "v1",
  "items": [
    {
      "textId": "YW-01-N01",
      "sceneIds": ["YW-01"],
      "startMs": 0,
      "endMs": 4200,
      "source": "scratch-read",
      "status": "draft"
    }
  ]
}
```

时长策略按顺序处理：

1. 优化译文，使表达自然且紧凑；
2. 调整同镜内停顿和字幕分页；
3. 在不破坏动作和连续性的范围内延长静帧、景别保持或转场；
4. 建立该 locale 的视频时间轴覆盖；
5. 仍无法容纳时标为 `blocked`，退回导演／视频实现评估。

不得以明显不自然的语速强行匹配中文时长，也不得静默删减事实。

## 六、字幕内部格式

项目内部字幕统一使用与渲染引擎无关的 locale 字幕 JSON；主题锁定的[实现 profile](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E9%A1%B9%E7%9B%AE%E9%85%8D%E7%BD%AE.md#%E5%AE%9E%E7%8E%B0%20profile)按稳定文本 ID 和毫秒时间读取：

```json
{
  "textId": "YW-01-N01",
  "text": "……",
  "startMs": 0,
  "endMs": 2400,
  "speaker": "narrator"
}
```

要求：

- 时间单位为毫秒，`startMs < endMs`，同轨字幕不倒序；
- `text` 中需要保留的空格不可被清理；
- 字幕层与当前视频母版使用同一时间基准；
- 每个 locale 使用独立字幕 JSON；
- SRT/VTT 从已确认时间轴导出，或导入后转成统一字幕 JSON 再进入实现；
- SRT/VTT 不是内部唯一事实来源；
- 字幕分页、行宽、字数和阅读速度按目标语言单独检查。

若采用词级高亮，必须另存可靠的词级时间数据，不得用平均分配伪装成精确同步。

## 七、语言审阅

每个 locale 至少完成：

### 内容检查

- 每个中文文本单元都有处理结果；
- 事实、证据层、改编标识和来源署名无漂移；
- 没有新增未经母版支持的神话结论；
- 人名、地名和称谓一致。

### 语言检查

- 语法、自然度、语域和角色口吻合格；
- 配音台本可自然朗读；
- 屏幕文字与口播的差异有明确理由；
- 数字、标点、大小写和专名符合 locale。

### 字幕检查

- 时间不重叠、不闪烁、不提前泄露后句；
- 断句按语义而非机械字数；
- 安全区、对比度、字体覆盖和换行适合该语言；
- 烧录字幕与 SRT/VTT 文本一致。

## 八、变更传播

| 变化 | 处理 |
|---|---|
| 中文标点微调且不影响朗读 | 记录，无需全部重做 |
| 中文文本语义变化 | 受影响 locale 标为 `needs-sync` |
| 单语言译文变化 | 只重审该 locale，并检查对应音频和字幕 |
| 文本 ID 变化 | 所有引用的音频、字幕和 QA 记录失效 |
| 镜号／场景边界变化 | 重建受影响语言时间轴 |
| 最终配音替换试读 | 用真实音频时长重定时字幕和画面 |

## 交接到音频

语言版本达到 `approved` 后，输出配音请求：

- locale、角色、文本 ID 和最终台词；
- 发音、情绪、语速和停顿要求；
- 文件命名、采样率、位深和声道要求；
- 每行独立文件或明确的整段切点表；
- 不可读出的屏幕文字和仅字幕内容；
- 台本版本与确认人。

正式音频只能绑定 `locked` 的语言台本。

## 完成检查

- [ ] 中文母版、分镜和视频版本均指向具体锁定文件。
- [ ] 每个可说／可显示文本都有稳定 ID。
- [ ] 首轮至少建立 `zh-CN`、`en-US` 条目。
- [ ] 每个 locale 有独立状态、台本、时间轴和字幕数据。
- [ ] locale 字幕 JSON 为内部格式，当前渲染后端、SRT 与 VTT 可追溯到同一时间轴。
- [ ] 译文保留事实、证据层、来源和改编边界。
- [ ] 没有把中文时长强加给其他语言。
- [ ] 尚未收到的音频只记录为需求，没有写成已完成。
