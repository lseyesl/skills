# 握拳塌陷与手指扭曲

适用：已有蒙皮手在指定动作中异常。先记录原文件、对象/骨架/动作关联、问题帧、关节尺度和目标姿势，固定对照视图；静止网格损坏时先处理基础几何。

| 区分检查 | 支持的原因 | 处理与限制 |
|---|---|---|
| 在副本临时禁用 Armature，异常仍在 | 基础几何或前置修改器 | 检查重复面、断裂、变换和修改器顺序，保留原骨架/动作 |
| 逐关节小角度弯曲，旋转中心偏离关节或发生侧摆 | 关节位置/骨轴 | 在副本调整，检查静止姿态与已有动作；不能直接 Apply Pose 改绑定 |
| 检查问题顶点 deform 权重，发现邻指/掌骨异常影响 | 权重污染或突变 | 仅修正目标 deform 组，清理/归一化后复验；控制组不混入 |
| 骨轴与权重合理，关节压缩仍折断、缺乏体积 | 拓扑或蒙皮方法 | 局部重拓扑或评估 preserve volume，先检查形态键/UV/权重依赖 |
| 基础范围正常，仅特定极限姿态失真 | 局部修正不足 | 评估姿势驱动修正形态键；检查组合姿势和驱动依赖 |

每次只改变能验证一个假设的最小范围；保存前后相同姿势/镜头证据。修正形态键前先排除骨轴与权重问题。按 [角色交付契约](../../character-delivery.md) 检查基础权重；数值规范不证明视觉形变。按 [手部姿势](../../acceptance/hand-poses.md) 运行回归。失败回到被新证据否定的分支，禁止默认整手重建或删除原动作。
