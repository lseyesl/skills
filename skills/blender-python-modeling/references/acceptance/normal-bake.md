# UV 与法线烘焙验收

1. 记录最终求值网格/三角化、UV、切线约定、材质图、图像色彩空间、cage 和消费者版本。

2. 确认图片已保存且可重开，目标图像/UV/活动材质正确；检查实际 UV 间隙、分辨率与目标 mip 的需求。

3. 先验证无贴图时的基础阴影，再使用棋盘和法线图查看接缝、拉伸、翻转、漏烘焙与跨部件射线。

4. 正确样例：已知高低模烘焙；缺陷：数据图错误标为颜色、目标图像错误、射线跨部件；替代：不同合法 UV 布局及贴图分辨率，只要满足事先声明的目标。

5. 贴图文件存在或烘焙算子成功不等于视觉通过；无法检查的消费者/mip 明确 unknown。

来源与采用边界见 [制作来源](../sources/production-sources.md)。
