# 人手制作

适用：需要新建人手。先确定写实/风格化、指头数量、静态/可变形、特写距离与平台预算；明确手套/合并手指是否为设计，不默认五指写实。修复已有手先用 [形变诊断](hand-deformation.md)。

分析：从掌背、掌侧与侧面确认掌宽/厚、指长节段、指缝、指根和拇指根位置。未知背面注明推断，不按单张剪影直接挤出宣称完整。

选型：静态远景可使用简化体块；可弯曲近景使用连续掌体和独立可读指体，在关节压缩/拉伸方向布置足够边环，避免弯曲中心形成高价极点。拇指根需要支持对掌，不能只是与四指平行的圆柱。不规定统一环数；先做一指与拇指局部姿势实验，以轮廓及形变决定密度。

处理：先定掌体与关节标记，再连手指并检查指缝和厚度；确认轮廓后细分，最后绑定和添加指甲/褶皱等细节。保护已有形态键时不得直接改变顶点对应关系。为需要关节运动的手检查掌指/指间关节轴与活动范围，自动权重后检查跨指污染。

失败：静止轮廓不对先改形体，弯曲不对进入形变诊断；不能靠增加细分或纹理掩盖关节问题。按 [手部姿势](../../acceptance/hand-poses.md) 验收。静态手只认证静态范围，不标为可动画。
