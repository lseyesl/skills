# 法线贴图接缝、黑斑与烘焙错误诊断

适用：高低模烘焙、导出后法线方向/接缝异常。先读 [UV 与烘焙](../../uv-and-texture-baking.md)；依据：[烘焙、色彩、glTF I/O](../../sources/production-sources.md)。

记录高/低模、最终求值几何和三角化、UV 层、图像/色彩空间、目标切线约定、cage/射线、材质与消费者版本。保留原程序化材质，不在唯一源上替换。

| 区分检查 | 更可能原因 | 处理 |
|---|---|---|
| 未接法线图时也有阴影问题 | 几何/法线/变换/三角化 | 先修基础，别重复烘焙 |
| 凹凸整体反向或单一方向反转 | 切线约定或通道设置 | 核对生产/消费端约定后配置；不默认翻绿通道 |
| 平面出现大面积异常 | 数据图经过颜色转换、错误空间/强度 | 确认 Normal Map 节点与数据色彩空间；固定显示变换比较 |
| 狭缝/相邻部件漏烘焙或串色 | 射线未命中/跨部件命中 | 分离烘焙组，检查 cage、方向和距离，不一律增大射线 |
| 只在 UV 边界或远距离出现 | 岛边界/切线/三角化/padding/mip | 使用最终三角化，检查实际像素间隙及目标 mip；必要时重烘 |
| 图片空白/只覆盖部分材质 | 活动目标图像、选择或 UV 不正确 | 逐材质确认活动图像节点、低模活动对象、UV 和保存路径 |

先用一块代表性表面和低成本设置验证命中，再输出完整贴图。任何拓扑、UV、法线、三角化或 cage 改动都应使相关烘焙证据失效。pixel padding 使用实测 UV 间隙与分辨率计算，不把 Blender 不同打包 margin 模式简单当成同一数值。

按 [烘焙验收](../../acceptance/normal-bake.md) 检查。无法消除的切线差异应记录消费端限制，不能只交 Blender 内的好看截图。
