# 基础形体验收与细化前置条件

先声明用途、目标模块与控制证据，检查项由具体任务确定。至少包含实际视觉检查；物体存在、顶点数或细分等级不足以授权细化。

- 比例：尺寸、相对位置、参考关键点或已明确的设计参数。
- 轮廓/体积：必要视角、深度、厚度、主截面、负空间，不能只靠正面相似。
- 结构：部件/重复数量、对称/非对称、连接和独立关系。
- 功能：需要时检查轮轴、转向/装配间隙、关节位置和活动空间；静态雕塑不额外要求动画。
- 可细化性：当前表示是否支持下一阶段；Cube 盒式建模与基础体组合都可以合格，任意相交体不自动等于连续可变形表面。

对影响交付的遮挡部位，在同一粗模上分别检查原图可见特征和隐藏关系。选能揭示该关系的视角、局部剖面或连接检查，例如从斜后方沿肩带追到固定点。记录实际看到的连接、间隙或层次。原视角吻合但换角出现意外互穿、悬空或断接时，退回该模块修正；证据仍不足则记未知。若用户明确指定固定镜头错视等特殊构造，按指定范围验收，其余部件沿用通常结构。

容器和机械连接按 [内容诊断与修复](../procedures/modeling/containers-and-connections.md) 测量：杯底多位置轴向射线、把手两端可达距离、辐条到轮圈/中心的连接路径。距离、拓扑路径和材料强度不是同一结论。默认对象清理、导出和实际用途另按 [可用资产](usable-asset.md) 验收。

在建模计划逐项定义结构/视觉/功能检查；review 用与计划一致的 check ID，记录 passed 状态、具体 finding、非空且哈希匹配的证据。视觉项还要标识 view，unresolved_issues 必须为空。不能因“已运行 builder”把模板 unknown 改成 passed。

证据文件相对 review JSON 所在目录，只允许其目录内的后代路径。结构测量也要保存报告；截图文件存在、哈希和状态格式一致只证明证据可追溯，工具不鉴定图片是否正确。

既有资产可以 method=reuse，保存源快照并检查实际状态后直接进入 review，不需要重建。局部修复只选择受影响模块，记录其他必要依赖；审阅后移动依赖部件、修改源网格/比例/连接/表示方法或参考会使相关回执失效。

粗模通过不等于 feature-complete/final。模板默认细化派生副本，不原地改变已审阅的粗模；精细输出后续仍需自己的视觉、形变和交付验收。对采用原地控制笼的成熟项目，必须提供等价的冻结控制状态与依赖检查，不能直接关闭前置检查。

inspection_signature 必须对应实际被检查的粗模、计划、作用域和依赖。修改形体后，仅重跑记录函数而不更新实际检查将被拒绝。每次新建草稿保留 pending/unknown，实际检查完成后才填写 passed。

计划可为模块声明 world_dimensions（整个绑定模块的世界轴对齐尺寸）和 dimension_tolerance；模板会测量实际求值几何并在超差时阻断。没有声明数值目标时不推断正确尺寸；共享网格的局部区域需项目自定义测量。默认状态/测量适配 mesh/curve，其他表示应提供等价适配器或可检查代理。

## 参考角色的粗模剪影

在第一次细化前冻结粗模，按校准好的控制镜头输出无材质干扰的前景遮罩。先对齐整身的投影、姿势、中线、地面和比例，再锁定相机，用同一画幅叠加参考与粗模。保留两种颜色分别标出的参考多出区、粗模多出区，以及重合区。局部特写从同一配准画面裁切，保持相同比例；局部单独缩放或居中会掩盖偏差。单张原图能确认的外形优先对照原图；侧厚等推定结构标明所用多视图及其依据。

每个适用的控制视角在模块计划的 `checks` 中分别登记整身、脸型、颈部、躯干。使用不同 ID，例如 `neck-front`、`neck-right`，设置 `kind: visual` 和对应的 `view`。归入现有语义模块即可，共用网格无需拆分。每项保存有哈希的双色叠图、局部参考与粗模并排图，并在 finding 中写明偏差的位置、方向、大小或可复核的边界判断。

| 部位 | 正面检查 | 侧面检查 |
| --- | --- | --- |
| 脸型 | 颧部至下颌角的收窄、下巴宽度及高度 | 额鼻、唇颏转折和下颌底线 |
| 颈部 | 下颌至领口的露颈高度、两侧颈宽和颈肩转折 | 下巴至喉部的负空间、后颈接入肩背的位置 |
| 躯干 | 肩宽与肩斜、腋下负空间、胸腰收束 | 胸背厚度、腰线和肩背弧度 |

头发遮脸、衣领挡颈、袖子盖住胸廓时，整身遮罩只能判断可见外缘。另用部件遮罩或无纹理渲染标出粗模内边界，同参考可见的下颌线、领口或服装边界对照；把不可见的解剖边界标为推定。缺少决定形体的方向时，补充经审阅的多视图或局部参考。明显错位或证据不足的项目保持待修或待查，修粗模后按原镜头复拍目标、邻区及整身。所有相关检查通过后再细化。全身重合率不能单独放行局部检查。

## 建模前生成逐视角清单

多视图通过审阅后、创建粗模前，按已校准的控制图填写 [建模计划模板](../../assets/modeling-plan-template.json)。按模块将模板的 `control_views` 换成本次有依据的视角，视觉检查的 `view` 沿用同一名称。无视觉参考的原创任务可省略此字段。每个控制视角至少对应一个检查，同一视角里的独立风险分配不同 check ID。把锚点命名与参考工作区统一，记录像素坐标时同时记录裁图版本、尺寸和原点。隐藏边界注明推定依据。

| 清单项 | 参考图上的标注 | 通过依据 |
| --- | --- | --- |
| 交领与胸口 | 正面标领口交点；侧面描领口到腰线的可见前缘 | 锚点叠图核位置，侧面裁图核前缘的深度和走向 |
| 袖口与腰结 | 侧面描袖口前后缘、最低点，圈出腰结与垂带露出的区域 | 固定镜头的分件纯色图能看到相应边界、遮挡顺序和可见范围 |
| 上衣与裙身配色 | 分别圈选同材质的中间调，避开接缝、高光、阴影边缘 | 在材质试渲染中，用相同镜头、灯光、曝光与色彩管理复测同区域的中位色 |

上表为角色示例。根据实际参考定义检查，在 `criterion` 写明标注来源、要观察的边界及允许偏差。跨模块遮挡登记相邻模块的 `depends_on`，让袖子或腰结的改动使原审阅失效。先看整身叠图，再看从同一画幅裁出的局部并排图。只要关键部位被挡或边界错位，该项保持待修；定位原因、调整几何后，用原相机复查目标部位、邻区和其他受影响视角。

取色安排在材质阶段。将同一画幅中各样区的像素矩形写入 JSON，例如 `{"jacket":[274,344,287,357],"skirt":[274,604,287,617]}`。坐标原点在左上，依次为左、上、右、下，右界和下界不包含。确认两张图中各框均落在对应可见材质内；若被遮挡，先复核几何。对已对齐、同分辨率的 8 位 sRGB 图，在技能目录运行以下命令并保存结果。比较渲染外观的色差，结合参考图照明和任务容差判断，调整材质后用原样区复测。

```sh
uv run python scripts/compare_material_patches.py reference.png render.png patches.json > material-review.json
```
