# 统一姿态与构型

整套控制图沿用同一主体状态、原点和相对尺度。投影方法、特定产品的示例以及本 Skill 为便于建模采用的姿态约定分别记录。

<a id="choose-one-subject-state"></a>

## 按对象选择构型

| 对象 | 建模参考的构型与视角 | 检查点 |
|---|---|---|
| 固定姿势成品 | 沿用指定姿势生成首图、正侧面与补图。 | 坐姿汉服女孩雕塑在正面核对膝与手的位置，侧面核对骨盆承重、座面与脚底关系；粗模使用同一组控制点。 |
| 可复用或用途未指定的类人对象 | 默认 A pose，双臂斜向下外展，手离开腰胯，双脚略分；各面保持同一肩、肘、腕和手形。 | 用正面检查手臂与躯干间隙，用侧面检查肩、骨盆与脚底。动作图单独保存。 |
| 四足动物 | 本流程采用符合物种解剖的平衡站姿；用正、侧面约束肩髋与足底，必要时补背面或脚掌。 | 锁定头颈、尾巴与承重状态。侧面两腿重叠时补局部视图，保持原站姿。 |
| 有翼动物 | 选择收翼或展翼的一种状态贯穿主体图。要建展开翼，可另做整套展开翼局部图。 | 标注翼根、翼尖、左右及与躯干交叠关系；两种状态分开标记。 |
| 车辆与机械 | 锁定车轮转向、悬挂、门盖及铰链状态。用侧面定位轴心，用前面和顶面约束宽度与偏置。 | 需要打开舱盖观察时另画局部或装配图。 |
| 刚性产品、道具 | 以稳定支承面或装配面定基准，选最能说明形状的一面为主视，再补能显示厚度或孔口的方向。 | 保留不对称孔位及安装侧；遮挡的独立配件另图表示。 |

**依据及适用范围**

- ISO 5456-2 规定技术图样正投影的基本表示规则。机械及刚性产品可据此选择投影；本 Skill 的图集应显式标注观察方向，若采用第一角或第三角布局应注明并统一使用。概念图仍以原图可见信息为尺寸依据。[ISO 5456-2](https://www.iso.org/standard/11502.html)
- Airbus A320 机场规划手册中的飞机外形图可供有翼车辆参考，对照顶面机翼展开轮廓、机身中心线和侧面高度。具体构型取自任务原图，手册中的机型尺寸只适用于相应飞机。[Airbus A320 手册](https://www.airbus.com/sites/default/files/2023-05/Airbus-techdata-AC-A320_0523.pdf)
- Blender Rigify 提供四足等不同骨架模板，可参考相应关节布局。上表的四足站姿与收展翼选择是本流程的出图约定；遇到特殊物种，依其解剖和用途选择可重复的状态。[Blender Rigify 手册](https://docs.blender.org/manual/en/4.5/addons/rigging/rigify/basics.html)

<a id="lock-the-reference-frame"></a>

## 锁定参考坐标系

记录：

- 规范的正向、向上和subject-left/right方向；
- 一个稳定的起源或接触地面规则；
- 中心线或根部参考点；
- 语义标志，可以在不同视图之间进行比较，例如脚底、膝盖、骨盆、肩膀、视线、车轮轴、铰链中心、屋顶线或连接点；
- 每个控制面板的常见正交比例。

将每个控制面板视为围绕固定状态的相机变换。不要单独旋转主体、弯曲部件、重新分配重量、改变软部分的运动，或将每个面板适配到其自身的轮廓限制内。

<a id="source-pose-conversion"></a>

## 转换原图姿态

将动作参考转为可复用绑定姿势时，标准化姿势属于推定。固定姿势成品沿用指定的关节和支撑关系，只推定遮挡或透视造成的不可见部分。在证据允许的范围内，保留身份、解剖结构、服装构造、附件位置以及比例等特征，但在记录姿势转换时，将不确定的关节或隐藏体结构标记为**未知**。

请不要声称该软件能够恢复精确的关节中心、隐藏的解剖结构、真实深度或单张图片中的测量数据。

<a id="readiness-decision"></a>

## 判断能否开始建模

仅在所有控制视图达成一致的情况下，将页面标记为 **Blender-blockout-ready**。

- 所声明的下游用途与已审姿态；固定姿势成品保留指定姿势，可复用类人角色采用约定的中立姿势；
- 记录的姿态或机械配置；
- 根部、原点、接触地面、中心线以及语义标志；
- 规范轴左侧、右侧含义；
- 常见的正交缩放；
- 附件来源及主要剩余轮廓。

如果不匹配会导致建模者在矛盾的结合点中心、附件位置、轮廓或体积之间做出选择，请将图纸标记为**仅预览**，列出冲突点，并将其作为设计依据，而不是作为设计权威。

姿态标准化并不能保证拓扑结构、关节变形或绑定准备的就绪。在锁定姿态中，应保留解剖学上所需的遮挡关系；添加辅助关节视图，而不是通过一个控制面板移动隐藏的肢体。
