# 关节与修正形态键验收

1. 分别验证 Basis、目标姿势、相邻姿势、左右、多个驱动与其他形态键组合；固定镜头/材质/尺度保存前后证据。

2. 检查骨轴/权重问题已排除，修正仅影响声明区域；驱动符号、空间、范围和组合合理，无重复叠加基础变形。

3. 拓扑/Basis/权重/骨架/修改器或绑定参考改变后重新验证；目标格式用实际重载或引擎确认。

4. 正确样例：局部形态键只在驱动姿势改变局部；缺陷：左右驱动反号、Basis 被破坏、修改权重后旧修正失真；替代：原生形态键或可选 Pose Shape Keys，按实际结果而非插件身份验收。

5. 两骨骼管段只校准数据行为，不认证完整人手、肩部解剖或动作品质。
