# 镜头与质量验收

目标是形成证据充分的差距与修复判断，不以“皮影感很好”或技术分数替代审阅。以下检查适用于实际作品；本技能编写时的参考抽帧研究不构成成片品质认证。

## 镜头设计

- 一镜先确定观众必须看见的事件。关键手势、接触、受击或表情要有足够屏幕空间和停留时间。
- 全景建立位置、出入口与行动轴；中景展示关系和动作；近景强调表情、持物或事件。切近景前后保持人物朝向、视线、道具状态和空间关系。
- 人物缩小并非一定失效：参考 B 的远景用于交代山峰空间；但若事件依赖手中小物，应改变构图或补镜头。
- 相机移动须有目的，如跟随、揭示或关系变化。静止舞台可依靠人物调度形成变化，不强制每镜推拉。
- 对话先安排说话者、对象、听者反应；人物并排不等于互相交流。主动作发生时减少抢眼的无关循环。
- 用视觉事件交代因果；字卡补充难以直接表现的信息。借鉴 A 的图文结构不意味着每镜都要字卡；借鉴 B 的动作舞台不意味着删除必要解释。
- 字卡／字幕检查目标语言字号、阅读时间、安全区、行宽和背景对比；音轨存在不等于已听审。

## 分阶段审查

| 阶段 | 必看证据 | 可下的结论 |
|---|---|---|
| 概念 | 全身、局部、同框样张、状态图 | 外观／结构设计可读；不能称已可动画 |
| 可动资产 | 原姿态回组、单关节端点／中间、关键组合、实际动画预览 | 指定动作与范围内可用；不能泛称任意动作可用 |
| 代表镜头 | 正式资产、正式背景、目标画幅的原速短片及接触帧 | 该镜头／风险类型通过；不能代替整片 |
| 整片 | 完整连续播放、逐镜问题表、跨镜状态、听音和导出检查 | 只对已审范围和版本作结论 |

每次修复保留前后同时间点证据与产物版本；再检查相关上下游镜头。工具成功、哈希一致、骨骼连通和视频可解码都只是技术事实。

## 参考品质对照表

评分采用 `通过 / 差距 / 失败 / 未验证 / 不适用（说明原因）`，不把它变成加权平均总分。指定参考时间码和产物镜号／时间码，在相同显示尺度与可比景别下对照。

| 维度 | 对照目标与检查问题 | 推荐证据 |
|---|---|---|
| 造型与纹样 | 轮廓与身份稳定？部件、线刻、服饰和场景是否统一？纹样有无游走、拉伸、闪烁？ | 远景缩小、近景原尺寸、跨镜对照 |
| 可动连接 | 肩肘腰髋及宽袖是否断裂？补全外露或错层？透明边缘是否污染？ | 极端／中间组合、正式镜头逐帧 |
| 动作与接触 | 支撑、抓握、承托是否可信？跳跃有落点？攻击与反应有因果？ | 原速连续片段 + 事件前后逐帧 |
| 场景与镜头 | 主要动作是否能看清？地面／水线稳定？层次与剪辑是否说明空间？ | 全景、中景、近景及切点对照 |
| 叙事与声音 | 无台词能否读懂关键事件？对白、反应、字卡和音效是否合拍？ | 全段播放、听音、目标语言阅读 |
| 全片一致性 | 角色状态、尺寸、朝向、道具、服装、光色与行动结果是否延续？ | 逐镜状态表和整片复审 |

不能以精美画面抵消结构断裂、关键接触失败、因果错误、身份漂移或整片未审。目标是达到“选定参考维度、指定范围”的品质；不同故事与镜头复杂度不宜宣布一个无范围的“同等品质”。

## 修复优先级与导演处理

1. **阻断交付**：关键动作或内容缺失，断肢／错人／核心因果错误，工程或素材无法打开，关键接触完全失效。先在授权范围修复，不扩大未验证镜头的批量生产。
2. **必须修复的显著差距**：滑步、穿插、层序错误、转向跳变、纹样漂移、明显不一致的光色或读不完的关键字幕。
3. **可记录的精修项**：非关键次动作、局部装饰密度、轻微环境循环等；是否可留待成片评审由项目目标决定，不能偷偷降级质量要求。

导演先定位根因并处理；无法处理的项形成记录：ID、镜号／时间码、目标、实见缺陷、影响、尝试与结果、备选修复、所需输入／权限、复审方式、当前状态。默认不因一般专业选择打断用户；尊重用户已约定的集中审阅安排。硬阻断不能标为通过，也不能伪造用户批准。

## 交付清单

- 实际视频、可编辑源与复现入口，所需资产可解析或已正确打包。
- 角色／场景／道具版本与原生组件 manifest；推测区域和已验收范围。
- 镜头、时间坐标、动作事件、运动分工、接触与跨镜状态映射。
- 参考对照与审阅范围；静帧、原速、逐帧、听音分别记录方法和结果。
- 未解决问题及建议处理顺序；未检查项写“未验证”，不留空冒充通过。
- 输出分辨率、fps、时长、音轨、编码与文件身份。技术验证不证明视觉质量。
