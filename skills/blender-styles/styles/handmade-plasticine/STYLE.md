# Handmade Plasticine / 稚拙手捏橡皮泥

把“被手揉、压、贴、拼出来”的制作痕迹变成可编辑的三维形状。风格包括有方向的挤压体积、局部指纹、未抹平的接缝和少量混色；先保持参考比例和组件位置，再添加这些痕迹。

这是 `blender-styles` 下的手捏橡皮泥风格模块。用 [blender-python-modeling](../../../blender-python-modeling/SKILL.md) 负责场景检查、参考图导入、关键点校准、Python 执行和保存；其参考匹配与人工介入规则优先。需要柔和、整洁的低多边形黏土风时使用 [soft-clay 风格](../soft-clay/STYLE.md)。

先遵守 [共用流程与验收](../../references/workflow-and-review.md)。软黏土基础工具现统一位于 `blender-styles/scripts/`，它们只是可选基础。

反复拟合角色参考时，使用 [可执行评估与局部修正系统](../../../blender-python-modeling/references/reference-fitting/workflow.md)。其中 [handmade_surface.py](../../scripts/handmade_surface.py) 提供分区、固定种子的三频表面，复用原材质工厂；通用建模层负责遮罩、相机、参数搜索和回滚。已有案例验证了闭环运行，手捏风格的视觉校准仍未通过，不能用 IoU 代替艺术验收。

## 风格目标与边界

- **体积像手捏的。** 有轻微压扁、局部鼓起、按接处的挤边；主要轮廓不会因为贴了噪声材质就自动成立。
- **瑕疵有原因。** 指纹位于可能被手指按住的地方，接缝位于拼装处，混色位于接触或揉合区域。留出相对平静的表面，避免全身均匀凹凸。
- **稚拙仍有结构。** 保持参考头部宽高深、五官关系、肢体粗细和接合逻辑。随机位移造成的头部塌扁、断裂腿形、五官漂移属于错误。
- **橡皮泥保持致密。** 表面可有弱蜡感、指腹抹亮和少量色屑；避免石头孔洞、海绵组织、陶瓷釉面或塑料玩具般均匀光滑。
- **表情可按需拆换。** 简化人偶默认考虑附着在固定脸上的独立眼、眉和嘴；具体是否采用贴片由用户设计决定。道具不强制长脸，用户要求一体雕塑表情时不擅自改为贴片。
- **可复现且可检查。** 使用稳定命名、任务所有权、确定的随机种子和项目内配方；不清空无关场景，不覆盖原始文件。

## 工作流程

1. **确认风格证据。** 查看用户当前参考。需要这套风格的一般示例时查看 [assets/style-reference.png](assets/style-reference.png)：它是 AI 生成、用户认可的美术目标，不是实物测量或模型成功案例。提炼体积、拼接、表面和表情规则，不复制其中人物身份到其他任务。用户最新参考优先。
2. **建立参考工作区。** 按 [通用参考流程](../../../blender-python-modeling/references/reference-image-analysis.md)，先拆分并导入 Image Empty、设置半透明与前景显示、轴向可见性、统一基准和比例，再开始参考驱动几何。查看正侧面实际叠图，保留校准记录。AI 局部错误按来源证据和结构逻辑解释；重大且不能判断的选项交由人工确认，其他明确区域继续。
3. **记录风格与比例约束。** 从 [风格记录模板](assets/style-brief-template.json) 创建项目内副本，填入真实来源、比例基准、瑕疵分布和面部方案。未确定的尺寸留为空，不能把模板当作自动建模配置。保持造型定位记录与美术参数分开。
4. **先校准局部样例。** 首次使用此风格或新增关键表现方法时，按 [校准与验收](references/review-and-calibration.md) 先做小样：挤压头形/贴片表情、厚片拼接、连续肢体连接。只做本次任务相关的样例。已有同类、同尺度、同渲染条件的通过证据可以复用，但要检查差异。未通过时先修小样，避免批量制作整个角色后才发现方向不对。
5. **建立干净的参考形体。** 按 [结构与制作痕迹](references/construction.md) 确认主要轮廓、头部深度、五官关键点和沿肢体的宽度，再进行手捏变形。保留一个可回退的干净基形；同一模块的艺术瑕疵不能移动其定位基准。
6. **分层制作痕迹。** 大的压扁、挤边、接缝和可见撕边用真实几何；中尺度压痕与抹痕按镜头需要采用几何、雕刻/置换或稳定贴图；细纹由材质补充。每层单独检查，限制对眼睛、贴合面、关节和轮廓的影响。
7. **制作可替换五官（适用时）。** 在同一个固定头部上放置独立浅浮雕组件，使用经校准的脸部局部坐标或稳定表面映射，检查弧面贴合、厚度、接触阴影和侧视间隙。通过替换组件或显示集合切换表情，不为每套表情重新猜头部坐标。
8. **材质、灯光与动画。** 按 [材质与灯光](references/materials-and-lighting.md) 调整致密橡皮泥的颜色、弱蜡感和局部磨抹痕。可复用 soft-clay 的工具，但其默认微凹凸不是本风格的完成方案。动画仅在请求时制作；先处理变形、接触与纹理稳定性，定格节奏可复用现有工具。
9. **比较并交付。** 按 [校准与验收](references/review-and-calibration.md) 分别判断参考形状与手作风格，保存匹配视角、细节和表情切换证据。失败项回到对应配方修正。报告脚本、配置、`.blend`、图像、推断/人工决策和限制；代码可运行、对象齐全、账本通过都不能代替视觉判断。

## 验证状态

当前是待视觉校准的风格规范，未附带经过认可的 Blender 成功样模。参考图只说明目标；历史上未通过用户验收的模型不能当作风格已实现的证据。将来只有在实际小样和任务结果经检查后，才能记录对应 Blender 版本、渲染器、尺度、镜头和适用范围；不要将一次通过推广为所有角色或输出都已验证。
