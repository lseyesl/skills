# 关节形变修正与修正形态键维护

适用：骨轴、基础权重与拓扑检查后，目标姿势仍发生局部体积/轮廓失真。先走 [手部形变诊断](hand-deformation.md) 或 [角色交付](../../character-delivery.md)，不能直接加修正掩盖上游错误。来源：[Corrective Smooth / Pose Shape Keys](../../sources/production-sources.md)。

## 方案分支

| 观察 | 处理 | 必须复验 |
|---|---|---|
| 扭转时体积丢失，基础骨轴与权重合理 | 在副本比较 Armature Preserve Volume | 其他弯曲、极限组合、目标导出后的蒙皮差异 |
| 局部网格形变过于粗糙/折皱 | 尝试局部 Corrective Smooth 遮罩与强度 | 轮廓、体积损失、边界、静止参考及修改器顺序 |
| 特定姿势缺乏肌肉/关节造型 | 制作姿势驱动修正形态键 | 驱动符号/空间/范围、相邻姿势及多修正叠加 |
| 修改权重/约束后原修正变形失效 | 从保存的目标姿势形体重新更新修正；可选 Pose Shape Keys | 原目标姿态、左右与全部组合；不能推断拓扑改动也安全 |

## 可复现处理

1. 保存源文件、静止 Basis、拓扑/顶点身份、骨架/动作/权重和目标姿势。冻结用于比较的帧、镜头和材质。
2. Corrective Smooth 的原始坐标参考依赖输入顶点关系；前置 Mirror/Subdivision 等生成型修改器改变拓扑时按运行版本选择/重建 Bind 参考。绑定记录改变后失效，不复用旧通过结论。
3. 制作修正形体时保存“对应姿势下想达到的表面”，不要把该姿势的整套骨骼变形再次作为修正位移叠加。为各修正定义局部遮罩和驱动，左右符号分别测试。
4. 用一个问题关节做局部实验。若换权重/骨架后需更新修正，保留目标形体，按所选维护方法重建并跑完整回归；拓扑变化单独转入 [数据迁移](../modeling/data-transfer-repair.md)。
5. 导出端不一定采用 Blender 相同的蒙皮和修正逻辑；按消费端决定烘焙/形态键/派生绑定，保留可编辑源。

按 [关节修正验收](../../acceptance/joint-correctives.md) 检查；不存在统一的最佳平滑强度、固定关节环数或固定手指修正数量。
