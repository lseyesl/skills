# 建模前的多视图审查

将生成的建模参考交给 Blender 前，逐张查看实际图像，再开始制作细节几何。生图成功、填完 JSON 或事后渲染模型，都无法补做这一步审查。

对生成的视图，单独保存[原图忠实度审查记录](source-fidelity.md)，用哈希标明原图与生成图，记录必须保持的可见特征和各部位的对比结果。下面的外观及结构检查也须执行。各视图即使彼此一致，若偏离原图，仍不能用于忠实重建。

<a id="review-in-this-order"></a>

## 审查顺序

1. **姿态是否适用。** 根据模型用途，检查头部相对脊柱的朝向、肩与骨盆的位置、关节弯曲、四肢间距，以及尾巴或翅膀与身体的间隙。例如，头正对镜头可能与躯干的中立姿态矛盾。类人主体的建模视图必须全部采用同一 A pose，成品姿势另作参考。对有表情的主体，先确认基准图符合常态或用户指定表情，再在各视角可见处比对眼睑开合、嘴角、下颌开度及耳位。若整套沿用了原图的瞬时表情，先修基准图再重做受影响视图；若只有某一面变了表情，用已审基准修正该面，并复查对应线稿。
2. **轴向与投影。** 根据形体确定解剖学左右、前向、上向和相机方向，再核对标签。检查正、侧、顶、底视图是否为严格正投影，遮挡关系是否合理。不要为了显示被挡住的肢体而改变姿态。有方向性的特征须附[根部至末端的标注检查](consistency-review.md#directional-landmarks)，并注明哪些部位因投影冲突或尚未确认而排除。
3. **比例与对应关系。** 对齐地面或原点、中心线及比例尺。在能看到相应部位的视图中，比较关节中心、头眼鼻高度、身长与厚度、肢体宽度及连接点。使用局部叠图或特征点表，按具体设计确定容差。记录统一缩放，不要通过拉伸单张图片来掩盖姿态或结构冲突。
4. **角色特征、结构与颜色。** 检查重复部件数量、不对称特征、连接处、灰白分区、耳朵正反面、胸腹、爪背与脚掌，以及尾翼等附属结构的末端。纠正生成图错误时，以原图证据和合理的身体结构为依据；继续标明推定和未知部位。
5. **拆件与局部图能否装回。** 在整图定位部件，核对各方向的接口、侧别和相对尺寸。放大图应带邻接结构或可对应的定位点。若连接面全被遮住，记录推定；互相矛盾时仅阻塞相关区域。
6. **线稿对应。** 先审查有明暗或材质的视图，将通过的视图保存为不可覆盖的源文件。单独制作线稿，再排版，避免重新生成已经通过的视图。线稿若偏离原视图，只作补充参考，也可从已审粗模提取实际轮廓。

逐张审查，包括已否决或仅作补充的视图。记录每张可信视图能约束的部位和尺寸；逐张看起来合理，还须确认这些视图能同时描述同一个三维形体。

<a id="annotated-contour-edit"></a>

### 用轮廓标注修正局部投影

1. **确定目标线的依据。** 同姿态、同观察方向的可信参考能直接用于建模时，优先复用。确需重绘时，记录参考来源和可见边界。只有正面图时，侧面厚度仍属未知；用户选定的手绘轮廓可作为设计目标，记录为设计选择。若任务要求还原原物，该厚度需侧照或相应实测依据才能获准用于建模。
2. **配准并标线。** 先核对视角和姿态，按共同高度等比缩放、对齐地面，再以部件连接点定位。例如以腰部为锚，在待修改侧图的副本上分别描出裙摆的目标前缘、后缘和下摆。仅描有依据的可见段，保留手部遮挡；框选可以指示编辑区域，目标线则指示边界应到达的位置。透视或姿态不匹配时，先取得可比视角，再做轮廓叠合。
3. **提交两张图。** 图一用干净的待修改图，图二用同尺寸、同裁框的标注副本。提示词示例：“沿图二蓝线调整图一的裙子前缘、后缘和下摆。保留腰部连接、手与裙子的遮挡、腿部位置、材质和相机构图。输出无辅助线的侧图。” 分别保存修前图、标注副本和候选图，在生成记录中登记各自的哈希及标注依据。
4. **按同一坐标复核。** 编辑前按用途和分辨率约定容差。将候选图按原锚点叠回参考，在相同高度分别记录前缘、后缘相对锚点的有符号偏差，并检查下摆高度；总宽相同也可能发生整体偏移。对照干净底图复核连接点、遮挡、邻区和辅助线残留。超差或出现邻区漂移时，保留原候选和冲突记录，记录已通过的测点和待修部位。将修后候选放回整套图，在共同姿态与尺度下逐一核对相关视角；整套通过后再交接干净控制图。对手绘设计线的贴合程度单独记录，原物隐藏面的忠实度仍为未知。

<a id="register-detached-parts"></a>

### 拆件配准与手掌方向

- **同尺。** 选两端均可见的一条刚性基准边（箱壳宽度不含侧筒），分别在共享该轴的面板量像素。记录原始裁框、像素长度、相对偏差及预设容差。确因局部放大而不同，记录一个等比倍率，并用第二对独立锚点验算。非等比拉伸会掩盖构型冲突。侧面用壳高与正面对应，再用壳深与顶面对应。
- **软带。** 先注明受力／展开状态、佩戴侧与贴身安装面；原图不可见的离背量标推定。侧图沿带内缘描出从上接口、最大离面位置到下接口的连续弧，量贴身面到带内缘的净距。前后图确认安装侧和横向偏置；侧图确认高度和深度。边视因遮挡无法观察时允许局部放大或辅助剖示，标明其依据。
- **成对软带的可见路径。** 左带与右带各登记自己的上固定点、带身和下固定点。先定哪个视角应见两条完整路径，哪个视角会因重叠只见一条弧，再出图。验收时从每个上端沿同一条带追到对应下端；把遮挡段与真实漏画区分开。贴身面留空、带身合并或端点换侧时，该面不能约束装配。
- **三个视角的共同坐标。** 对相邻零件选可重复定位的中心或轴线。例如金属环中心 R 与圆筒盖中心 C；以刚性安装面为深度零点，声明向外的正方向。正面约束横向差和高度差，边视约束有符号深度差和高度差，顶面须同时重现横向差与深度差。先以独立的刚性长度核对倍率，再量两点之差。上方零件若遮住下方零件，应按投影显示遮挡，并用可见圆弧或边缘推定中心，注明误差。禁止为了同时展示两件而在顶面将其摊开。留出一个未参与拟合的视角；零件无法定位时记录未知。
- **接口。** 在整件与局部同时标出可重复定位的邻接物、折返点和固定件中心。以安装面为零深度。用两面建立粗模，第三面或未参与拟合的锚点验证。记录误差、铆钉可见性和穿插；仅有单一视图吻合时限定通过范围。
- **手。** A pose 单独记录掌心、拇指和指尖相对角色自身的方向。若掌心向前且腕中立，正面应见掌面、背面应见手背、严格侧面以手缘为主，指尖仍沿前臂斜下。侧图可见掌面宽度取决于实际扭转；只因换相机而变成掌心向地，应标记前臂或腕部姿态冲突。

<a id="decision-and-construction-scope"></a>

## 审查结论与建模范围

- **通过（passed）。** 事先列明的必需控制视图齐全，两项审阅（原图忠实度、整套一致性）均完成并通过，所有建模冲突已有解决依据。冻结最终干净图及哈希。
- **部分通过（partial）。** 留在多视图审阅阶段，列出已通过的部位、待补视图及未解决的冲突。补充视图不能直接用来确定尺寸。
- **阻塞（blocked）。** 整体姿态、轴向或投影仍冲突，或目标部位缺乏足够证据。返回修图或补充依据，再做整套复核。

统一使用分层部位名称，如 `head.skull`、`head.muzzle`、`body` 和 `tail`。允许 `head` 即包含其子部位；口鼻部仍受阻时，不能批准整个头部。选择某一视图解决冲突时，记录实际采用的证据、它能确定的尺寸及选用依据。若歧义会改变角色特征，需要时遵循人工判断流程，不能将其改称为无害的简化。

若修图反复破坏先前通过的视图，保留各候选和冲突记录，补充参考或请用户确定设计，再复核整套。标注副本和未通过候选留作审阅证据。

## 建模交接记录

将 `multiview-review.json` 与项目参考图一同保存。以下是两张控制视图的最小示例；若生成五或六视图，还须记录其他每张视图的用途和观察结果。实际审图后再填写哈希和结论。

```json
{
  "schema_version": 1,
  "purpose": "供后续绑定的可复用四足角色",
  "pose": "四足均衡站立，头与脊柱对齐，肘与跗关节微屈，尾部放松，与背部和腿部留有间隙",
  "required_views": ["front", "right"],
  "readiness": "passed",
  "checks": {
    "pose": {"status": "passed", "finding": "记录各视图实际可见的关节姿态及头部朝向"},
    "proportions": {"status": "passed", "finding": "记录统一比例尺、地面和特征点对比"},
    "projection": {"status": "passed", "finding": "记录实际相机方向与遮挡检查结果"},
    "structure": {"status": "passed", "finding": "记录部件数量、连接点和不可见结构的推定"},
    "appearance": {"status": "passed", "finding": "记录色块、耳背、腹侧及不对称特征的检查结果"},
    "axes": {"status": "passed", "finding": "前向为 -Y，上向为 +Z；已确认鼻尖朝画面左方的原图是从 +X 观察的右视图"}
  },
  "allowed_regions": ["head", "body", "tail"],
  "blocked_regions": [],
  "conflicts": [],
  "views": {
    "front": {"image": "reference/front.png", "sha256": "actual-file-sha256", "role": "controlling", "controls": ["head", "body"], "finding": "记录正面的特征点与形状"},
    "right": {"image": "reference/right.png", "sha256": "actual-file-sha256", "role": "controlling", "controls": ["head", "body", "tail"], "finding": "记录侧面轮廓及关节位置"}
  },
  "review_artifacts": ["review/reference-landmarks.png"]
}
```

视图角色为 `controlling`（用于确定形体或尺寸）、`supplemental`（补充）或 `rejected`（否决）。每处冲突记录 `severity`（`critical` / `local`）、`status`（`resolved` / `unresolved`）、`finding` 和受影响的 `regions`；解决后填写 `resolution`。生成前按用途登记 `required_views`；完成审阅后逐项绑定干净图、哈希和结论。部分通过时先保存进度；Blender 仅在整套通过后使用冻结版本。更换任一控制图时重新审阅整套并更新记录。

图像及审查文件的路径相对于本记录，参考视图路径相对于 Blender 配置文件。安装 `blender-python-modeling` 后，运行 `scripts/reference_review.py <reference-setup.json>` 检查源文件哈希、证据声明、视图用途和获准范围。工作区辅助工具会在导入多张视图前执行此检查。脚本无法判断图像内容、解剖结构或实际模型是否遵守声明范围，仍需审查参考图与网格。

<a id="character-and-item-handoff"></a>

## 角色与配饰的交接

在现有结构检查项中，把每张视图与配饰清单及其所属主体逐一核对。检查数量、左右侧和长度，重点查看背部、双手与衣缘。在全图可见时检查身体特征点。出现凭空增加的配饰、缺失的一体式结构或挡住必要特征点的道具时，重新审查受影响的视图和部位。修正该图或生成缺少的独立视图，再与原图和其他视图复核。已审且未受影响的部位仍可使用。

角色与配饰分开交付时，列出角色视图、各物件的独立参考、组合原图或显示安装位置的局部图，以及各图能确定的部位。按记录的左右侧、连接点及相对尺寸验证物件能否装回。角色视图有意省略的可拆物件仍须在项目清单中有对应记录。
