# 结构与制作痕迹

## 从参考基形开始

执行 [参考工作区流程](../../../../blender-python-modeling/references/reference-image-analysis.md)，把可信正面/侧面的中心线、眼线、鼻嘴位置、头顶、下巴、肩、膝、脚底等转换为模型约束。头部深度从可信侧面或多视角体积判断，不能用“贴片五官需要平面”作为把整个头压薄的理由。参考本来是圆头时，仅在局部获得适合贴附的面部曲率。

头身比例与肢体厚度由当前参考决定，不在通用风格中硬编码大头、细腿或某个年龄。把身份/比例层和制作痕迹层分开，先验收前者，再建立后者。无图任务可提出合理美术选择，但要说明这是设计，不是匹配出来的尺寸。

## 用制作过程解释形状

| 可见效果 | 对应做法 | 检查重点 |
|---|---|---|
| 指腹捏扁的头或躯干 | 基形上的宽缓、局部压缩与体积再分布 | 多视图有厚度，不出现无意塌陷 |
| 手搓的肢体 | 连续中心线和半径轮廓，局部抹压 | 膝肘前后粗细连续，不像串珠或两根尖椭球相碰 |
| 压片衣物 | 有厚度的片材、轻微不均的边缘、折接处堆积 | 边缘可读，身体或裙底没有无意露洞 |
| 接合处挤出的泥 | 接口周围局部挤边、压痕、残留缝 | 有支撑和接触，不悬浮或形成深黑裂缝 |
| 粗捏头发/装饰 | 相互压接的少量泥团或片条 | 不能变成均匀球珠、规则鳞片或遮住关键五官 |
| 撕边、刮痕 | 局部方向明确的不规则边缘/压槽 | 不全身重复，也不破坏目标轮廓 |

服装可以是贴片、薄壳或与身体连成一体，由设计证据决定。不可为了显示“拼接”强行增加参考没有的大圆补丁或装饰。接缝也不必都开放：被手抹过的接口可以只有浅浅的体积变化。

## 控制不规则，而非随机破坏

- 先规定痕迹发生的位置、方向、大小和覆盖范围，再给受控参数加入固定种子的变化。
- 对称零件共享基础剖面；需要的左右差异单独记录。不要给每条腿独立噪声后再将粗细不一致称为手工感。
- 保护眼线、鼻嘴锚点、接触面、关节、鞋底和绑定所需拓扑。施加位移前设置相应的区域权重/遮罩。
- 按最终观看尺度工作：改变轮廓、产生清晰视差或接触阴影的痕迹需要几何；亚像素级细纹可留在材质中。不要把低多边形数量当成本风格必要条件。
- 保留干净基形和独立的变形参数/修改器，发现造型错误时能关闭痕迹层复查。

## 连续肢体与关节

沿肢体中心线记录数个半径采样位置，至少覆盖端部、中段和关节两侧。用连续剖面、适当融合或变形网格连接。可保留浅拼缝，但皮肤主体应有合理接合；避免尖端接尖端、腰缩、膝盖圆片突兀贴上、左右厚度不可控等问题。

若用户希望可动拼装玩偶，应明确设计关节；不要把穿插和缝隙事后解释成关节。动画角色沿用 [角色交付](../../../../blender-python-modeling/references/character-delivery.md) 的绑定与变形规则，不能在绑定后随意重网格化。

## 可替换浅浮雕五官

该构造适合简化表情人偶，不代表可制造的真实拆装机构。

1. 用可靠参考标定脸部局部坐标：中线、眼线、眼距、眉眼距离、鼻嘴距离和嘴宽。记录原图位置以及对应的模型坐标。不同表情可按设计改变形状/位置，但共享同一坐标框架。
2. 头部作为固定实体保留，不切出嘴洞或眼窝来伪装贴片。鼻子、耳朵、发型等固定组件按参考设置。
3. 眼睛、眉毛和嘴巴各自独立。用浅扁网格、带厚度轮廓或有意压扁的曲线构成，让手捏边缘有轻微变化。需要圆环嘴时中心仍能看到脸部表面。
4. 贴片顺应局部脸面曲率：使用经检查的表面采样、投射/贴合修改器或稳定的局部映射。设置小而一致的表面偏移和厚度；不要使用一个固定全局深度摆放所有五官。
5. 从正面检查关键点，从侧面/斜侧检查埋入、悬空、互穿及投影。厚度随角色和镜头尺度调整，没有通用绝对毫米值。
6. 每个表情一组组件集合或明确的替换清单；切换只影响允许变化的对象。需要时比较头部顶点/变形状态，证明其未被意外改动，但这项结构检查不能证明五官位置正确。
7. 先做好一套表情的贴合和比例，再批量扩展。眉毛被头发挡住、鼻子和嘴环相交、眼睛被压进脸等均视为未通过，不能靠表情可切换来抵消。

物理磁吸、插销、最小壁厚、拆装间隙和可打印性属于额外交付，需要真实尺寸与相应工程验证。
