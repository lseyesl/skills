# 皮影角色图片生成

先设计连接，再设计花纹。目标是一张结构可解释的平面影人图，不能只给普通汉服人物加镂空与圆铆钉便视作完成。

## 适用边界

- 新生成或修正皮影人物时使用；纯剪纸装饰、普通汉服插画不强制套用活动结构。
- 风格与结构分开：用户可以改变材质、颜色、年龄感与装饰密度；“明亮风格”“不用还原材质颜色”不表示放弃分件和连接。
- 无参考图时可以设计，但注明所选结构为设计方案。用户指定地域、流派或要求传统复原时，先查看对应实物参考；不把默认方案说成所有中国皮影共有的标准。
- 本技能交付静态图片。需要独立 PNG、绑定或动作时，再使用仓库内的 [shadow-puppet-part-splitter](../shadow-puppet-part-splitter/SKILL.md)，不能凭静态图片宣布可动画。

## 生成前：确定结构方案

先读 [结构约束与检查](references/structure.md)。有参考图时实际查看，并区分可见事实、隐藏推测和拟修改之处；无参考时直接采用可解释的方案，不要求用户先提供素材。

在工作记录中用几行写清以下内容，再将关键约束放入生成提示词。无需另做工程文件或要求用户批准方案。

1. **朝向与姿态**：默认侧脸、接近平面投影，躯干可适度半侧表达服饰，避免明显透视缩短。无动作要求时用易读的站姿；用户要求舞姿等则保留动作并检查遮挡。
2. **部件与连接**：说明头颈属于哪片、头身如何衔接、上身与下身在哪里搭接、腿脚是一体还是分片、手与前臂是否一体。按角色和用途选择，不固定十一件或强制每处有铆钉。
3. **前后遮挡**：明确颈根藏在领口后、下身顶边藏在腰带/上身后、腿根藏在裙片后等关系；固定花饰与活动连接区分开。
4. **可见性**：只画设计要求露出的肢段。裙下结构可以遮挡，但不能让露出的鞋直接挂在裙摆花边上。完全遮住的连接标为未能从成图验证。
5. **风格**：保留用户所选配色与材质。未要求时不额外加入操纵杆、舞台、拆件拼版、编号和尺寸。

## 生成与局部修正

使用环境中实际可用的图像生成/编辑能力，并遵循对应工具规范；不绑定某一家供应商。工具不可用时交付结构方案及提示词，明确未生成图片。

提示词顺序：角色与服饰 → 平面造型 → 具体分件/搭接 → 姿态与遮挡 → 配色和装饰 → 禁止的结构错误。不要只写“关节正确”或“传统皮影风”。

可按当前方案改写以下结构段，不能将例子原样套给所有角色：

> 头、发饰与颈片作为一体头茬，颈片下端伸入领口后；上身与裙身为搭接的两个平面片，腰部收窄但保留连接宽度，腰带遮住搭接根部；裙下露出的短小腿与绣鞋采用一体侧面剪影，腿根向上延伸并被裙片遮住。连接处由片与片交叠构成，不用悬空铆钉代替连接，不添加脚背圆钉或肉色球形关节。

这是一套便于读图的现代设计方案，不是传统工艺定论。若用户需要独立踝部或转头控制，修改对应方案并明确其设计属性。

编辑时锁定需要保留的脸、花纹、配色和姿态，只改失败的连接及必要的邻接轮廓。保持源图，另存修正版；工具无法精确保留局部时说明限制，不声称像素不变。

## 生成后：必须看图

实际查看全身及头颈、腰部、腿脚局部，必要时放大；按参考中的检查表逐项记录“通过 / 失败 / 遮挡不可验证”，不能将提示词包含约束当作约束已实现。

- 头颈有连续根部并进入领口，头茬与躯干的关系可解释。
- 腰部上下片确实搭接，腰带没有掩盖断裂或重复躯干。
- 每只露出的脚能追踪到对应腿片，鞋头朝向、近远侧关系和姿态一致。
- 肩肘腕符合所选分件，关节点落在两片重叠区；花纹和宽袖没有掩盖断肢或多肢。
- 外轮廓、孔洞和连接桥可读，没有将应连接处镂断；完整角色没有被画布裁断。

优先修复结构失败，再调整装饰。默认最多两轮针对性修正；仍有失败时如实交付为待修正概念图，列明部位，不用更多花纹掩盖问题。不将目视推演旋转称为实际活动测试。

交付实际图片位置，简述结构选择与残余问题；区分“静态连接目视通过”和“运动未验证”。项目使用的图片与检查记录放在任务输出目录，不放入技能源码。
