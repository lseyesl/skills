# 汽车车轮制作

适用：新建轮胎/轮毂或车轮组件。先记录静态/可旋转/转向、镜头距离、尺寸依据、悬挂间隙、坐标轴与输出目标；车轮运动异常使用 [运动诊断](wheel-motion.md)。

选型：远景胎纹用法线/贴图，轮廓可见的胎肩和近景深胎块用几何；轮毂放射结构采用旋转复制或实例，按渲染/导出需求转换。不要为不可见内壁和胎纹一律增加几何，也不能用贴图替代特写中影响轮廓的结构。

构建：以轮轴为共同局部轴，轮胎用受控截面旋转成形，轮毂保持同心；需要不同材质、替换或运动的部分分对象。轮子旋转枢轴置于轮轴中心，转向枢轴另建父级，不把转向和滚动混在任意欧拉轴。在测试副本验证对象变换后再决定应用，不能破坏已有绑定。

检查：用同一轴向检查各截面中心、半径、宽度；转一周观察偏心与侧摆；装车后检查刹车、翼子板、转向和悬挂行程间隙。胎纹应跟随轮子且接缝连续。运行 [车轮验收](../../acceptance/wheel-motion.md)。面数降低必须在目标距离复核轮廓、阴影与运动，并测实际目标开销。

铸造轮毂要检查每根辐条在内外端与中心盘/轮圈的实际连续关系，不能只记录十根分支或靠螺栓遮住径向间隙。按 [连接诊断](../modeling/containers-and-connections.md) 区分半径错误、缺桥接、相交未融合及层级问题。用明确区域路径配合截面和法线检查；相近不等于足够强度。

制作 rotation clip 后在 0/90/180/270/360°比较实际表面，至少有非零转角和可观察运动；完全不动的轮子不能因中心不漂移而通过。仅旋转资产不强制纯滚动；装车后才增加其对应地面/转向/悬挂检查。使用隔离交付 adapter 的 animated 模式时保留全部明确父级依赖，并检查 clip 和采样表面。

先按 [参考解释分支](../../reference-image-analysis.md#interpret-the-reference-before-tracing-or-choosing-geometry) 区分完整孔边界与透视/遮挡后的黑区。五组双辐需要组内和组间负空间、曲面及根部过渡；可先做一个受参考约束的扇区，验证后旋转复制，气门嘴和唯一标记独立保留。重复推断必须有源图支持，不能强制所有车轮对称。

建模计划预先声明总面数及阶段预算。先测一个扇区/胎块的求值成本，再估算重复后成本并实测整体。体素重构、细分和高密扫掠只有在代表区域的形状收益与完整资产成本都可接受时采用；不要到最终导出后才发现超限。胎纹用贴图还是几何由目标镜头/轮廓决定，优化保护开孔、铸造曲面、同心关系和动作。
