# 本轮实现与验证范围

2026-11-12，基于本地仓库 0a43d68（12 个 Skill）实现。在线仓库可能有较新入口；未将本地缺失的 Skill 注册为可用能力。

- 保留原 Skill 名称、依赖协议、锁定安装和制作路由。12 个入口都有唯一主分组和知识索引；Blender 追加条件处理方案、验收入口与风格索引。
- 新增中英文检索、硬条件排除、缺失事实提示、按 ID 获取及反向影响查询。验证路径、重复 ID、依赖与证据引用；锁定副本独立检索通过测试。
- Blender 主入口增加任务分析/现场诊断/方案选择；提供人手、车轮和绑定导出流程、独立验收与任务记录模板，复用已有台账/阶段回执。
- 提供 12 个领域任务契约与外部运行记录校验、检索回归、保守成对比较。任务成功率建议以不同任务为样本单位，不把同一任务的重复运行当成独立样本；成本变化单列。

已执行：轻量检查全部 10 个测试套件；新增知识/评测测试 12 项；检索 dev 3 例、test 11 例（含域外与条件拒绝）；Blender group 及新增领域夹具。Blender 4.3.2 中验证了正确/错误权重诊断、姿势求值、偏心/滚动数值反例，以及带骨架动作的 GLB 隔离重载与姿势表面坐标比较。

尚未建立：生产级人手/车轮/角色样例的视觉验收、目标引擎实测、Blender 4.5 基线复验、真实 Agent 旧版/新版成对任务结果。当前夹具是技术校准，不是生产资产。全部新知识保持 experimental；不能声称新版 Skill 已提高真实任务成功率。14 个手写检索种子仅证明这些案例的回归，不是独立盲测或全领域检索质量证明。
