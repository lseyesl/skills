# 动作与运动逻辑

以下为制作方法，不是对参考片幕后算法的断言。先建立空间、状态与事件，再调曲线；纹样刚性与关节表现不妨碍清楚的重量、意图和反应。

## 时间与控制分工

声明 fps、镜头本地帧起点、区间是否含终点、全片时间偏移、输入动作时长。变帧率素材用解码时间戳；不要用抽帧序号冒充原片时间码。分镜剪短／变速后同步更新事件、接触与音频映射。

分开五种运动：角色根路径、局部肢体、道具、环境、摄影机。每项只有一个明确负责者；烘焙序列已经包含的位移不能被后端再叠加。摄像机移动时以场景接触点检查滑步，不以画面像素不动作为唯一判断。

## 动作设计表

| 动作 | 先定的逻辑 | 关键姿态／状态 | 常见失败与修复 |
|---|---|---|---|
| 行走与停步 | 路线、速度、左右支撑脚、步幅 | 接触—承重—经过—摆腿；停步收重心 | 根位移与步频分离造成滑步；修根路径和支撑，不靠遮脚掩盖 |
| 挑担／推车 | 肩或手的接触、物品路径 | 持稳—迈步—停稳，道具有限滞后 | 肩手离物、吊绳伸缩；统一连接与运动责任 |
| 转向 | 转后目标、朝向与近远侧映射 | 停顿／引导—过渡—新朝向 | 人物瞬移、左右饰物交换；用验证过的状态资产或明确切镜 |
| 跳跃／翻腾 | 起点、起跳支撑、空中路径、落点 | 准备—离地—空中造型—接地—缓冲 | 中途换轴、落点穿地；分开根轨迹与局部翻转 |
| 跪拜／起身 | 膝、手、脚的支撑顺序 | 跪姿—前倾—伏地—停留—恢复 | 整人绕中心倒下；改髋腰头与支点关系 |
| 递物／握手 | 交接时间和双方触点 | 靠近—同时接触—释放—离开 | 物品悬空或同时跟随双亲；切约束时保持世界变换连续 |
| 举杯 | 手握点、杯口、嘴和桌面 | 举杯—靠近—收回—入口—放下 | 杯穿脸、手穿杯、液面方向错；重设锚点／遮挡 |
| 攻击／防守 | 意图、目标、武器轨迹与命中结果 | 预备—出招—命中／格挡／闪避—反应—恢复 | 先倒后打、空挥却命中；对齐事件与空间轨迹 |
| 四足／骑乘 | 支撑肢、身体路径、鞍部相对关系 | 步态与身体起伏、骑手随动 | 四腿同相、骑手飘离；独立设计四足循环并验证接触 |
| 变身／消失 | 前后身份、空间、姿态、携物状态 | 前态—遮蔽／转化—后态—结果 | 随机换人、物品消失；显式状态切换与锚点配准 |

## 接触与因果检查

每个关键事件记录 actor、target、时间／帧范围、接触锚点、起止状态、允许偏差、遮挡、预期结果。偏差按镜头显示尺度制定，不能给全项目套一个固定像素阈值。

- 支撑阶段检查接触点相对地面／台阶的位置；离地阶段才允许摆动。
- 持物若没有叙事上的松手，接触应连续。双手持杆需检查两个握点与杆长，不让约束拉长手臂。
- 击打检查武器扫掠路径、受击部位和反应时间；打偏也应有清楚的空间理由。
- 跳跃通常用可控弧线表达起落；神话飞行／定身可另设规则，但转折和停留要有表演依据。不能把“风格化”当成穿地、瞬移或断肢的解释。
- 倒地／起身后继承正确朝向、位置、携物与表情。切镜不能重置已发生的事实。

## 表演与节奏

### 逐人物校准行走，避免“全员同一循环”

对每位行动者单独记录：全步周期与半步、近／远腿相位、步幅与根路径、脚尖方向、头肩垂直范围、躯干倾向、手臂职责及持物约束。挑担、领路和端盘即使同向前进，也不能只换衣服后复用相同相位与摆臂。先对比展开、经过、蹬离、摆腿、停稳的轮廓，再微调中间曲线。

参考中的头、肩、腰、鞋底要分别观察；模板跟踪可辅助测量，但低相关度、遮挡和转头会造成漂移。头部位移不是人体重心或髋部运动的实测。先用静止场景锚点排除摄影机运动，重复纹样造成的跟踪跳变不能解释成相机位移。

身体起伏与脚触地必须一起修：支撑脚目标固定在场景空间，上身升降后重新计算腿姿，不能把整个角色（连脚）上下平移。髋部应处在两腿都可到达的范围；上身参考姿态与髋部高度不一致时，检查比例、髋点位置和腰部搭接，而不是强迫双膝一直深弯。区分上身控制点与髋部控制点，并检查它们之间的实际衣片连接。

需要两段刚性链时可调用 `scripts/planar_ik.py` 的 `solve_two_link(dx, dy, upper, lower, bend=1)`，返回静止方向向下的两段链的顺时针相对角度。它只解一个明确目标，不生成步态／支撑事件。必须为近远腿选择弯曲方向、校验活动范围；不可达目标报错，不偷偷缩短步幅、移动脚点或拉伸片件。还应检查摆腿即将落地时的可达性，不能只约束承重腿。

停步按“根速度减小 → 最后一步落地 → 另一脚收齐 → 身体升稳／停住”编排；不能冻结走路中段的屈膝姿态。持物角色让双手与道具继续保持可读承托，停止后不再无限循环行走起伏。为每个人分别提交原速片段、采样关键姿态和接触记录；隐藏在篮筐／衣摆后的腿可另做无遮挡诊断预览，正式镜头仍按参考层序，不用遮挡掩盖错误。

为每拍写动词与对象，如“看见敌人—举棒警告—挡住退路”，而不是“摆臂 30°”。先做观众能读懂的轮廓姿态，再处理头部关注、身体重心、手型和附属运动。

准备、执行、到位、停顿、恢复不必等长。挥击与犹豫不应使用同一种缓动。FK、IK、关键帧或替换片按可控性选择；肩肘等保持平面自由度与已验收范围。只在可读且风格一致的部位使用柔性变形。

主动作决定时序；袖穗、胡须、篮筐和旗幡是受它影响的次动作，有限延迟与衰减，不同部位不全部同相。对话听者也有注意力和反应，但不用持续摇头证明“活着”。群像错开小动作，关键仪式／冲击时刻保持叙事上的同步。

转身没有唯一标准：可用左右状态与过渡片、在遮挡中切换或切镜；仅绕 Y 轴转一张平面容易出现“薄纸消失”，需要有意设计，不能当通用默认。参考 A 的朝向差不能证明其采用何种转身。

## 环境运动

| 对象 | 运动组织 | 必查 |
|---|---|---|
| 波浪 | 远水、中浪、近浪／浪花分层，有限平移起伏或变形 | 循环接缝、纹样稳定、层间相位、水线和人物遮挡 |
| 雨与花瓣 | 统一风向基础上有尺度、速度和深度差 | 不遮关键手脸，不同镜头方向有解释 |
| 烟雾／变身 | 发源点—扩散／遮蔽—散去—状态揭示 | 前后人物和道具连续，不能用烟掩盖未做动作 |
| 火焰 | 附着燃点，主体轮廓与局部变化分开 | 热源位置、遮挡、强度变化与事件同步 |
| 旗帜／绳／穗 | 固定根部、运动端与受力来源明确 | 根不漂移、长度不乱变、循环不过度同步 |
| 背景视差 | 按镜头实际层深和摄影机路径设计 | 地面与演员接触不因错速被破坏 |

波纹的循环是设计建议；参考 A 05:17–05:21 的短片段不足以证明完整循环。参考 B 的火烟与残影在采样中可见，但实际合成方法未确认。

## 调试顺序

1. 在简化画面确认动作因果和根路径。
2. 校准支点、轴向、父子关系和接触约束。
3. 检查层序、隐藏搭接与目标活动范围。
4. 调整关键姿态、时序和注意力分配。
5. 加次动作、纹理、光效和声音，回到同一动作复测。

不能通过降低既定动作幅度、把脚藏进前景、删掉关键命中镜头或加大烟雾来假装通过；改变表演方案须明确记录其对叙事的影响。
