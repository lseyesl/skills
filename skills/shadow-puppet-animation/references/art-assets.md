# 资产设计与生成

本页是实施建议；来源实见见 reference-study.md。先定义视觉和动作需求，再生成可消费的资产，不把风格提示词当成结构保证。

## 角色与服装

给每个角色建立身份表：头脸轮廓、鼻眼眉、发饰、胡须、身段比例、主辅色、纹样、鞋形、关键配饰；左右按角色自身标识，另注画面近远侧。参考 A 用脸谱／服色区分人物，参考 B 以猴、猪、僧人、妖怪的轮廓和装束区分，不要求新故事复制这些造型。

1. 从实际分镜决定站、走、跪、俯身、抬臂、持物、翻身所需状态图。侧脸为常用设计，不强制所有物体永远正侧面。
2. 服装按运动功能设计：肩袖搭接区、肘部衣片、袖口手根、腰带遮挡、前后裙片、腿脚露出范围。长衣不默认补完整隐藏人体，但实际动作需要的连接必须有依据。
3. 刚性纹样跟随部件；必须局部变形时标出区域，检查镂空、边线和花纹被拉伸情况。头饰、穗、胡须只有需要相对运动才另拆。
4. 重要手型预制自然、指向、握持、行礼等版本；握持按具体物品设计。切换保持腕锚点、方向、大小和图层关系。
5. 转向／变装定义同一角色的状态资产及对应锚点。非对称衣襟、字样、佩剑不能整体镜像后不检查。参考中看见换装不等于已知其制作算法。
6. 近景和远景分别检查：最小展示尺寸下身份可辨，近景纹饰不过度粗糙。细纹不能密到缩小后闪烁或糊成黑块。

角色生成调用专用 image Skill；下面是增加到提示词的镜头约束，不替代其结构规则：

> 同一角色身份与服饰，侧面可读轮廓；为“提篮走路后停步递篮”设计，提篮手留出轮廓间隙，宽袖在屈肘时保留与躯干的搭接空间；固定脸、发饰、衣襟、主色与纹样尺度。先输出完整概念／关键姿态，独立部件在下一阶段提取。隐藏结构按项目策略标注，不在概念图中伪造编号、控制器或成品绑定。

## 场景生成与分层

先画构图和层表，标注地面／台阶／水线、行动路径、出入口、主要接触面、镜头范围与最大移动包络。每个生成层共享同一画幅、基准线和尺度，记录裁剪偏移；禁止靠每镜重新生成整张背景追求一致性。

| 层 | 内容与约束 |
|---|---|
| 底幕／远景 | 色调、纸／幕质感、远山与天空，控制对比，避免与人物抢纹样 |
| 中景 | 树、桥、房屋、洞穴等可辨场所；人物能走到哪里要明确 |
| 行动层 | 主角、配角和接触道具；保留完整动作轮廓与落足区域 |
| 前景 | 枝叶、岩石、柱、浪头；依据动作规划遮挡，不随机遮脸遮手 |
| 氛围 | 雨、雾、花瓣、火光等；可独立控制强度与生命周期 |

场景提示词示例：

> 皮影舞台式山道，远山低对比、行动地面为清楚连续轮廓，右侧松树与岩石构成边框，中部留出两人持长杆交锋的空间；线刻纹理与角色风格统一。分层制作，先出构图参考，再分别提供不含人物的远景、行动地面和前景，构图锚点固定。不要把演员、文字、光效与前景全部烘焙到同一张底图。

生成工具若只能输出整图，先交付概念，再制作遮罩／图层；不能假称一次生成了分层工程。固定摄影机可先使用静态场景，视差只在实际镜头需要时添加。

## 道具、动物及活动环境

道具资产记录：外形尺寸、握持／支撑锚点、质量感、活动轴、父级、可见层次、初始与结果状态。碗、担子、篮筐、手推车、武器、马、轿子不能共享同一种运动方案。

- 碗：手握点与碗口分开；倒向嘴时检查方向，必要时将近侧边缘独立绘制。
- 担子：肩接触、绳端、篮筐吊点独立定义；允许摆动但不能伸缩或脱离。
- 车：车把—手、车轮—地面、车身三者相容；不要给行走人物再叠一套独立车辆路径。
- 武器：握点、尖端／打击区与长度固定，双手持握时定义主从控制或约束；换手明确交接时刻。
- 马：身体、头颈、腿、尾与骑手按实际动作分件；骑手相对鞍部稳定，不把人步态套给四足动物。
- 轿子：共同刚体或稳定框架由统一轨迹控制，两位抬者对齐支点；转身和放下先排接触顺序。
- 波浪／旗帜／火焰：保留风格化轮廓，分离主体形、装饰纹、局部变化及遮挡片，按镜头决定粒度。

道具提示词示例：

> 与角色统一线刻和配色的侧面提篮，提手内空明确，手握连接区完整；独立透明资产，无人物、手、文字和烘焙投影；按目标画面尺度保留提手宽度，输出后检查 alpha、细桥与边缘。

## 拆件与可动性

用专用 splitter 的计划、mask、manifest 和工具；单张图尚无组件时先执行 [标注—编译—回组—试动](../../shadow-puppet-part-splitter/references/character-intake.md)。只收到概念图、拆件拼版或零姿态差分通过时，不得将角色记为动作可用。要求实际独立 PNG、隐藏区依据、目标动作及未通过范围，再安排镜头。这里仅补充镜头级约束。

- 一个控制节点可以驱动多个绘制片；运动父子树不能替代绘制顺序。遮挡成环时细分片，不靠不断调全局 z 值。
- 针对目标动作的端点、中间、组合姿态检验整条接缝扫掠范围。圆形关节连接正常不代表宽袖接缝正常。
- 原始可见像素、隐藏补全、状态替换各自留证。遵从 concept-covered／inferred-repair 合同，不静默补猜。
- 所有导出保持统一坐标与锚点；图像自动裁剪后修正偏移，不直接把裁剪中心当关节。
- 透明边缘在亮底、暗底和正式背景上检查；白底不是镂空证据，半透明不能无条件叠成双倍暗边。
- 资产合格须有回组对照、范围试动和正式镜头证据；静态 PNG 合格只表示静态阶段。

装配失败先用 [像素、轴与接缝诊断](../../shadow-puppet-part-splitter/references/assembly-diagnostics.md) 记录误差与候选修正；新编译资产的报告/hash 必须对应当前组件。blocked、文件已改动或仅有诊断输出时不记为资产通过。历史无编译标记的 manifest 需要补做明确验收，不因兼容加载成功而继承批准。

手、袖、身体或道具发生前后穿插时，把可验证的 front/back 意图和生效帧段交给 splitter 层级诊断，并提交实际姿态；静态层序无法满足时先拆绘制片或实现明确的换层，不以运动父级替代遮挡关系。
