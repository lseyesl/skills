# 参考图到可活动的二维组件

交付能单独变换、按原姿态重组、围绕关节活动的组件。保留参考图可见设计，隐藏区域标为推测。不要将生成的一张拆件拼版当作独立资产交付。

## 输入与默认值

必需输入是角色参考图。先查看图片；只有文件路径时使用可用的图片查看工具。没有图片时可给方案，不编造具体边界、坐标或已完成的 PNG。

默认：二维关节动画、原图分辨率、保留原姿态、按运动需求决定粒度、无操纵杆。默认试转 -30° 到 +30°，同时检查中间角度；实际活动范围以服装结构和用户动作要求为准。纸偶实体制作还需要材料、尺寸和连接工艺，透明 PNG 本身不证明物理可用。

## 1. 先定义目标动作，再确定结构

先写 `motion_plan.json`，记录目标动作、关节目标范围和代表性组合姿态；格式见 [Blender 绑定与试动](references/blender-workflow.md)。目标范围与验收范围分开：`motion_plan.target_ranges` 保留动作目标，`manifest.nodes[].rotation_range` 表示当前交付允许范围。初次拆件尚未验收时标为候选。固定需求未满足时报告未满足，不以静默缩小范围代替完成。

- 记录尺寸、朝向、姿态、背景和角色实例。区分观察到的边界、推测的连接及尚未知的信息。
- 按动作决定独立件：相对运动或换装的部分拆开，固定发饰随头，袖片随对应肢段；长袍遮住的腿不默认补出。左右按角色自身定义，并注明近侧/远侧或画面位置。
- 为每件回答：跟随谁、绕哪里转、根部被谁遮住、运动后露出什么。不要按颜色块盲拆或固定套用人体件数。
- 分开记录运动父子关系与绘制顺序。同一逻辑部件穿插到别的部件前后时，可拆成多个绘制片，共用控制节点；若存在遮挡环，先细分绘制片，不能仅调整一个 z 值解决。
- 产出 `parts_plan.json` 和带编号的边界、关节、遮挡标注图。计划字段见 [数据约定](references/manifest.md)。

## 2. 先验证代表性连接

选一条上臂—前臂—手，或最能暴露问题的连接，先提取可见片、配置候选锚点并原姿态回组。动画任务默认将这些初步资产导入 Blender，再根据目标姿态暴露决定隐藏补全；无需先补完全部部件。通过代表性连接后扩展全角色。仅要求 PNG/规划时不强制创建 Blender 文件。

## 3. 提取可见区域

- 为可见区域制作精确 mask，沿轮廓、衣边、接缝切割；保留花纹、细线、镂空和边缘透明度。不要按白色一键删除背景：白底、白纹样与镂空可能相混。
- 源图可见像素优先保留。将可见区与补全区遮罩分开保存，防止编辑器改写脸部或衣饰。
- 为可见像素建立唯一归属，回组前分别查看每个独立层，检查误留在躯干上的袖边与误划到手臂中的裙摆。已有可靠源 alpha 时，外边界可宽覆盖透明区，精确控制部件内部接缝，再与源 alpha 相交；宽覆盖不能跨入其他部位。

## 4. 在 Blender 中绑定并试动

读 [Blender 绑定与试动](references/blender-workflow.md)。每张 PNG 作为独立带 alpha 平面，用正交相机检查参考姿态；骨骼位置从静止全局锚点导入。每片刚性绑定到一个控制骨，固定发饰可随头；不默认使用自动权重拉伸皮影花纹。绘制片保持独立前后层级，多个片可共用一根骨。

按目标范围建立试验骨架，锁定平面外自由度，用 FK 和局部旋转限位控制关节；明确骨轴和屏幕角度转换。先试参考、端点、中间角度与关键组合。正式绑定使用已验收范围，试验骨架保留尚未通过的目标范围并标识不可作为交付动画使用。配套 `scripts/blender_rig.py` 支持这两个模式；MCP 可用时先检查现场并加载持久脚本，未连接时可在独立后台 Blender 执行验证，不能声称修改了实时场景。

记录每个失败姿态的部位与原因：锚点错、父子变换错、遮挡错、关节根部断裂、宽袖整段开缝、超画布或纹样被拉伸。骨骼连接和正确权重只证明运动关系；铆钉仍连接不代表整条衣片接缝无缺口。

## 5. 根据试动暴露补全，再回到同一骨架复测

- 仅补运动需要的扁平连接片，不追求完整隐藏人体。优先依据真实延伸、邻接轮廓、可靠对称、最小连接几何。约 12% 的肢段长度只作延长起点，通过旋转覆盖调整。
- 肩根伸入躯干，前臂与上臂在肘处交叠，手根伸进袖口，下身顶边藏进腰带；长袖、裙装优先补衣片。不要添加肉色球形关节或复制可见腰带。
- 简单隐藏连接优先用像素/矢量编辑；需要生成式修补时使用环境提供的图像编辑能力，并遵循其工具规范。读 [局部补全约定](references/repair.md)，提供原图、可见 mask、目标补全 mask、相邻片和关节位置。
- 将编辑结果限制在补全区，可见区从源图合成回来；保留软边 alpha，避免叠加软边造成暗线。所有推测区有实际遮罩和置信说明。
- 工具不支持精确遮罩或透明导出时，报告限制并改用可控像素流程。无法完成时只交付实际完成的阶段。
- 对宽袖开缝，检查整个接缝在目标动作中的扫掠区域，不能只增大铆钉处的小圆片。可调整隐藏衣片轮廓，或增加与原骨共控的背面搭接绘制片；逐姿态检查它是否填住原图镂空、改变原姿态花纹或穿到错误层级。刚性搭接仍无法满足目标时，报告结构限制；局部网格形变应作为明确的另一方案，另测纹样与镂空畸变。
- 每次补全后用更新纹理/部件重建相同骨架与同组目标姿态，保留补全前后对照。无法达到原目标时保留失败目标与实际可用范围；不要只给限位成功的截图。

## 6. 导出与组装

每个绘制片输出独立 RGBA PNG，不含背景、投影、编号或控制点。操纵杆如有需求，单独作为可隐藏图层。

按 [数据约定](references/manifest.md) 输出 `manifest.json`。统一原图像素坐标、左上原点、y 向下；保存裁剪原点、全局和局部锚点、父子关系、绘制顺序及活动范围。控制节点与绘制片可一对多。第一版不要额外缩放/旋转导出 PNG；如需转换，先扩展坐标约定和预览器，不能继续套用原坐标。

配套工具只负责**校验数据和组装已有资产**，不执行语义分割或 AI 补全。需 Python 3.10+ 和 Pillow（`python -m pip install -r scripts/requirements.txt`，使用项目选定环境）。以下路径相对本 Skill 目录，manifest 内路径相对 manifest 所在目录：

```bash
python scripts/puppet.py check /path/to/output/manifest.json
python scripts/puppet.py render /path/to/output/manifest.json --output /path/to/output/preview/reassembled.png
python scripts/puppet.py render /path/to/output/manifest.json --angles '{"forearm_l":30}' --output /path/to/output/preview/elbow-plus30.png
```

角度是相对参考姿态的偏移，正值在画面上顺时针。子节点跟随父节点；绘制片 z 值独立。预览画布固定为 `source_size`，越出画布会被裁剪，必要时另建宽画布审查，不把画面裁剪误判为连接丢失。

## 7. 验证与交付

四组检查都要有证据：

1. **原姿态**：并排、叠加或差分检查源角色与回组图，关注脸、轮廓、花纹、镂空和接缝。背景变化单独记录；差分不能替代目视检查。
2. **活动连接**：逐关节扫过端点和中间角度，再测组合动作，检查漏缝、重复边、补全外露和错层。工具的成功退出只表示数据合法与渲染完成，不证明连接或视觉质量通过。
3. **资产与坐标**：运行 `check`；确认透明背景、细节孔洞、无白边、独立可用。动画任务在 Blender 验证刚性单骨权重、静止回组、父子跟随、顺时针角度转换、前后层级和越界限位。FK 限位和 IK 限制分别处理；如另有目标引擎再验证导入，Blender 通过不能代替引擎验收。
4. **推测与限制**：高亮推测区域，列出低置信度部位及实际可用角度；把未检查项明确标为未检查。

交付目录包含：`parts/*.png`、`masks/*`、`parts_plan.json`、`motion_plan.json`、`manifest.json`、`qa_report.md`，以及 `preview/` 下的回组图、带 ID 拆件展示图、关节标注图、推测区高亮图和运动预览。动画任务增加可编辑 `.blend`、绑定/限位测试数据、目标与已验收范围差异；图片须打包进 blend 或随资产提供。辅助脚本只生成其说明支持的预览，其余图需实际制作。报告部件数、补全原因、测试范围、遗留问题与文件路径；未完成上述检查时不宣称已交付动画可用资产。

## 测试入口

运行 `python -m unittest discover -s tests -v` 检查工具的回组、父子变换、透明孔洞和非法数据拦截。真实角色行为用例见 [evals/evals.json](evals/evals.json)；合成样例通过不能替代真实参考图拆分验收。
