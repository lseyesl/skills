# 实测验证记录

本记录对应参考拟合系统首版，运行环境 Blender 4.5.12 LTS。不是手捏风格已校准或模型最终验收证明。

- [测试汇总](validation-summary.json)：49 项 host 单测、12 项新 Blender 集成、16 项真实闭环检查、5 项实际交付重开检查通过；25 项旧 Blender 回归与两个旧 host 脚本套件通过。
- [部位与颜色完整指标](metrics-table.md)：同一相机与标注版本；旧全局 IoU .8617 → 参数化初版 .8730 → 四轮局部修正 .8837。
- [参考/旧模型/新模型](model-comparison.png)、[局部修正前后与差异](iteration-comparison.png)、[多视角](multiview.png)。

四轮优化测试了 8 个双臂候选，选择 4 次；额外左腿两候选都无显著收益，回滚。头部未实质改善、头发低分、左腿相对旧基线下降与表面偏干净均未解决。数值不能代替 3D、五官和艺术验收。指标标注来自审核过的本例颜色/边界掩码，不是扫描真值。
