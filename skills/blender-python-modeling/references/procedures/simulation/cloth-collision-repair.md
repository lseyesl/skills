# 布料穿透、悬浮与模拟爆炸诊断

适用：布料与碰撞体的接触异常。先读 [模拟通用约定](../../physics-and-simulation.md)，保存源与现有缓存，记录单位、拓扑、修改器顺序、帧范围/FPS、碰撞集、pin 组、碰撞厚度与采样质量。依据：[布料碰撞](../../sources/production-sources.md)。

## 先定位再调参

1. 在副本回到模拟起始帧，检查初始交叉、极端尺度、薄片距离、pin 组和绑定后的实际表面。先修初始几何，不能用更多迭代治初始穿插。
2. 用 [制作诊断工具](../../../scripts/production_checks.py) cloth 模式列出 Cloth 对象、候选碰撞体、Collision 修改器和碰撞集合。必须在碰撞体上配置 Collision；布料参与对象碰撞与自碰撞分别设置。
3. 对碰撞缺失检查参与配置和集合；对快速穿透检查连续帧、速度与时间采样；对爆炸检查初始穿插、距离与约束冲突；对悬浮检查距离/厚度相对资产尺度。
4. 只改变一项可检验假设：增加距离可能减少穿透但增加悬浮，增加质量会增加计算成本。对远景旗帜与近景衣服分别决定自碰撞需求，不全场景统一最高设置。
5. 先试短接触片段，再冻结参数完整烘焙。更改拓扑、碰撞体、动画、pin、FPS、帧范围、单位或求解参数后使旧缓存/证据失效；只操作任务拥有的缓存。

连续失败时回到最早失败帧和最小复现场景，而非无限加分辨率或抹掉旧缓存。按 [布料验收](../../acceptance/cloth-contact.md) 检查。预检通过只证明配置存在，不能证明布料没有穿透。
