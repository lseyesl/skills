# 3D 纸模角色工作流

用于可全角度观察的折纸／纸壳角色与骨骼动画，不沿用 paper_theater 的整身图片运行时限制。后端仅为[Blender](https://github.com/lseyesl/ancient-tales-blender/blob/main/docs/backend/README.md)，状态与批准遵循[全流程总控](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E5%85%A8%E6%B5%81%E7%A8%8B%E6%80%BB%E6%8E%A7.md)，所有权遵循[资产所有权](%E5%B7%A5%E4%BD%9C%E6%B5%81-%E8%B7%A8%E4%BB%93%E5%BA%93%E8%B5%84%E4%BA%A7%E6%89%80%E6%9C%89%E6%9D%83.md)。

## 专项与影片边界

角色专项可以从用户批准的角色简报与动作测试契约开始造型；这不代表任何影片的 Gate 1–5 已通过，不虚构剧本、镜头或帧数对账。进入影片时必须重新核对 locked 剧本、导演、视觉与角色资产的具体版本，完成影片既定门槛。

每个专项使用独立 project_id 和视觉 profile。跨风格参考默认禁止；只有用户明确批准、按来源 commit／路径／哈希登记的有限参考白名单例外，不能据此搬用旧生产资源、模型、场景或旧批准证据。

## 造型定义

先完成高保真正面、侧面、背面与 3/4 造型候选，统一头身比例、服装结构、颜色及身份特征。补全不可见面是新设计，必须明确审阅。AI 多视图不是严格投影、拓扑或真实模型，不能以图片证明模型完成。

材质用有限折纸体积、哑光纸面、纸芯切边、分层覆片表达；禁止塑料、黏土、写实皮肤或给普通圆润模型仅叠纸纹。身体体积与衣片厚度分开定义，不强制整个人物同一薄片厚度。

## 参考拆解与校准

造型图已确认不等于三维比例已校准。开始网格制作或恢复重大造型返修前，实际打开绑定参考的正、侧、背与 3/4，先完成以下记录。视觉解释写入主题现有视觉定义／资产契约；标注图、校准渲染和建模控制数据放在所有者仓库，遵循跨仓库资产所有权。

### 参考拆解表

按部件建立稳定 ID；表中必须能定位原图区域，不能只写“参照原图”。

| 项目 | 必须明确的内容 |
|---|---|
| 来源 | 参考版本、仓库相对路径、哈希、视图名称、裁切框或标注位置 |
| 比例与轮廓 | 主体宽高深关系、外轮廓、关键转折与负空间；位置用统一坐标或相对头高等稳定尺度表示 |
| 部件结构 | 根部与连接点、体积朝向、覆盖者与被覆盖者、发尾／衣片端点、厚度方向 |
| 材质 | 纸面底色、粗糙度、纤维、切边、折面和接触阴影各自的证据 |
| 证据与假设 | 图中明确可见、跨视图推断、不可见面补全分别标明；冲突视图记录采用依据与待审问题 |
| 验收 | 对应模型视角、要比较的特征和允许差异；没有依据时不得自称达到像素级或1:1匹配 |

头部至少拆出头颅／脸形、五官、耳朵、贴头发层、束发／发髻、垂发／马尾、头饰；不把所有头发当成一个可随意叠片的整体。部件缺省与命名可按具体参考调整，不要求参考没有的结构。

### 比例和相机先于细节

1. 判断每张参考的视角、透视／正交特征与头部姿态。AI 多视图不是严格正交图；发现不一致时记录具体冲突，建立统一三维解释，不能声称一套模型必然精确匹配所有图。
2. 选稳定基准，如眼线与头部中心；统一单位、轴向、相机角度、焦距／正交尺度和裁切规则。相机尚不确定时先做校准，不能直接把投影差异误判为模型变形。
3. 使用少量灰材体积校准头颅宽高深、下颌、耳位、发髻与头饰的体量和位置。用轮廓／叠图／并排图对照，确认大轮廓和负空间后才细分发片、五官和表面。
4. 比较新旧模型时使用完全相同的相机、画布、灯光和裁切。参考可以做有记录的等比缩放和平移；禁止非等比拉伸、局部变形，或分别按新旧轮廓重新适配尺度来掩盖比例差异。展示用自动适配图必须标为示意，不能代替校准证据。
5. 几何问题用中性灰材、轮廓和正侧背判断；材质问题另用固定中性光与正式光判断。整体比例未解决时不以“更像纸”替代造型验收。

## 覆片结构与纸材

发片、衣片和配饰覆片必须有逐件控制数据，至少包含：所属层、根部／连接区域、中心走向、宽度变化、末端轮廓、厚度、覆盖关系与所依据的参考区域。片数由可见结构决定，不以复制更多片作为默认修复。

### 层叠关系先于片数

先画或记录覆盖关系，再建立结构灰模。以参考明确要求“上短下长”的马尾为例：上层短片位于外侧，盖住中层根部；中层继续覆盖底层根部，底层长片从下方露出。这里的“上／下”同时涉及可见高度和覆盖顺序，不能误写成横向长短错落，也不能让外层最长片遮住全部内层。

- 先用分层显色图和侧／背图检查根部连接、短中长端点及深度顺序；再用完整灰材检查真实遮挡。隔离视图可解释结构，但不能单独证明组合后可见。
- 上层短片的尖端、中层与底层露出区域须在目标视角实际可见。中心线在空间中不相交，不代表有宽度和厚度的整片不穿插。
- 禁止用一片巨大发帘或无依据的补片填满所有空隙；先判断该处是参考中的自然分离、接触阴影，还是会透出背景的错误贯通缝隙。
- 柳叶状长条须保留连续长轴、中段宽度、渐收尖端与实体侧边；不能只把矩形末端削尖，也不能用细线代替根部延伸。尺寸、层数与厚度按本项目参考确定，不固化为所有角色同一组参数。
- 结构调整先检查相关层，保留候选前复查正、背、左右和 3/4；任何依赖当前模块确认的下一模块仍按用户门禁执行。

### 材质不得替代结构

纸质感按实体厚度／切边、有限折面、哑光底色、纤维细节和接触阴影分别检查。厚度以场景单位记录，并在侧视近景证明；纯平面描线不是实体厚度证据。

切边材质只作用于真实边界，避免整片变浅、宽金边或共享材质使皮肤／头饰意外改变。增加边缘遮罩时检查粗网格插值、窄片、尖端和束发带；新增网格采样或修改厚度后复查轮廓、法线与穿插。材质调整不得静默改变已保留的脸形、发片走向和层次。

## 内部造型检查点

下表细化现有制作顺序，不新增 Gate 或默认要求用户逐行确认；批准范围和模块门禁仍由总控及用户明确要求决定。

| 检查点 | 最小证据 | 未通过时的动作 |
|---|---|---|
| 参考解释与校准 | 可定位的拆解表、视图冲突记录、相机和尺度依据 | 修正解释或校准，不继续猜测性加细节 |
| 大比例与轮廓 | 同条件正侧背灰材／轮廓对照，关键点观察 | 返回头颅、脸形及主要部件体量 |
| 结构与覆盖 | 分层诊断和完整灰材多视图，逐层露出与连接关系 | 修改根部、方向、覆盖顺序或片形 |
| 厚度与纸材 | 侧边近景、中性与正式灯光，保留项回归图 | 修正实体边、折面、遮罩和接触阴影 |
| 当前模块送审候选 | 真实标准多视图、逐项 ledger、已知差异和未批准范围 | 按 Blender 主入口返修，不进入受限下一模块 |

实际返修、重复失败后的方法调整和结果报告统一按[Blender 固定证据与返修](https://github.com/lseyesl/ancient-tales-blender/blob/main/docs/backend/README.md)执行。技术灰模和未通过候选必须如实标记，不能因有多视图或技术检查通过而改称完成还原。

## 资产契约

契约至少包含项目／角色身份、版本、造型参考及权限、比例、单位、坐标朝向、建模姿势、拓扑与 UV、衣发结构、材质、控制骨／变形骨、IK/FK、接触点、表情、动作范围、人工接管范围、交付物与证据要求。

角色有真实正侧背体积及可编辑网格，不以 billboard、正面贴图挤出或单图投影作为最终角色。建模先匹配已确认造型，绑定后检查关节、袖裙、五指、足底及侧背面。

## 制作与审阅

局部探索只渲染能暴露问题的视角，保留可恢复源与简短观察；例如修改一片头发先检查相关视角和遮挡。保留候选时复查受影响项，模块送审时才按上表补齐多视图与逐项证据。比例、骨架等共享结构变化扩大复查范围；未修改且依赖未变的证据按总控复用。用户限制的模块边界不变。

顺序：路线／契约 → 多视图造型确认 → 完整网格与纸材 → 骨骼及变形 → 连续动作测试 → 可编辑角色包。阶段 2–3 可先用技术灰模验证拓扑，但灰模不冒充最终造型。

动作测试同时包括固定关键帧、正侧视图、连续播放与测量；角色触碰外物时，对象落地、表面接触和释放连续性必须共同成立。控制点误差小不等于视觉接触合格。

模型生成与装配采用外部 Python 持久源；人工精修先登记受保护数据块，重建不覆盖。按 Blender 主入口验证依赖、场景、骨骼与证据 ledger。用户确认只批准被审版本和哈希；概念图、模型、rig、动作各自的批准范围不得混用。

## 交付

当前制作仓库保存定义、提示词、脚本、manifest、批准与追踪；模型、贴图、rig、Action／NLA 和真实渲染存 HF，并由项目清单锁定哈希。正式消费依赖具体 locked 版本，候选使用稳定新版本路径；不得覆盖旧项目。

2026-09-07 最小环境验证：macos-panel，Blender 4.5.12 LTS，BLENDER_EEVEE_NEXT，Python 3.11.11，factory-startup 后端探针通过。此证据只证明运行环境，不证明角色质量。
