# 图片到可用 3D：本轮 Skill 优化与验证

日期：2026-11-13；在 main 工作树修改，未新建 Skill。旧图片基准输入、日志、模型与 51.75/44.5/41.5 分保持原样，没有重写为更高分。

## 已落实的执行变化

1. **新建空任务场景**：`production_workspace.task_scene` 区分 create/edit；创建不复制默认 Cube、Camera、Light，同任务重复执行复用场景，同名未拥有场景拒绝清理。模板和参考拟合器接入。编辑显式命名原场景；清理不跨场景删除共享对象。正常保存后实际验证默认打开活动场景。
2. **实际渲染预检**：用独立 16px CPU 场景探测渲染和降噪。仅明确不可用的降噪器允许回退；其他错误传播。拟合器 beauty/clay 使用同一实测策略，保留 render-record，避免原案例依赖手工补救。
3. **隔离 GLB 交付**：显式白名单打包，在新 Blender 进程限定活动场景与选择；静态冻结求值副本，动画/蒙皮使用显式准备的原生副本。重载比较网格、求值三角面、双向顶点云、基础 PBR、clip、skin 和骨层级，并按源 FPS 对齐采样。拒绝静默丢弃程序材质、形态键和约束，支持范围外沿用专门准备/审阅路径。
4. **内容专属检查和修复流程**：增加世界坐标端点距离、至少三位置的轴向底厚、明确区域拓扑路径。文档区分接近/相交/焊接/承载，提供原因—处理—重验分支；修复预算和每次失败进入任务记录，旧回执必须失效。
5. **真实持久绑定入口**：`character_rig` 使用已审阅的 3D 关节和逐顶点权重创建持久骨架/蒙皮，创建前拒绝无效绑定，不替换已有 rig。补充肩/肘/膝、目标预算、静态拟合与动画交付的分级验收；fitter 报告求值三角面并支持任务 max_triangles，仍明确为静态拟合，不把 probe_only 升级成生产角色。

所有详细内容归入现有 Blender Skill。知识索引新增生产工作区、容器连接、可用资产三条，相关工具依赖同步；五个开发任务契约与六个检索回归查询新增。状态继续 experimental，没有用单测证明真实 Agent 效果。
