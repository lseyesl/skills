<a id="concept-multiview-sheet"></a>

# 概念图转建模多视图

B 中每个视角都应能辨认出 A 中的同一个对象。生成前从 A 选出可核对的特征，例如头身比、轮廓转折、单侧标记、色块边界、表面材料或笔触。转换姿态或视角时逐项保留，使 B 能同时约束形体、厚度与连接位置。保留原图可观察到的特征，明确标记隐藏结构的推定和未决之处。从照片或现有设计制作模型时，先按[原图忠实度流程](references/source-fidelity.md)核对主体身份。除非用户明确要求重新设计，否则以忠实还原为目标。原图忠实度与跨视图一致性分别验收。

人物、类人生物和动物的建模参考默认采用符合该角色或物种的自然静息表情。从首张基准图到各视角、头部特写及对应线稿，沿用同一表情。原图中的大笑、眨眼、咆哮等瞬时动作在建模图中还原为常态；原图仍用于核对身份特征。用户明确指定表情时，各视图沿用指定状态。

新角色在首图定稿前做[成片尺寸下的辨识度检查](references/source-fidelity.md#character-readability)，随后将选定特征纳入原图忠实度审阅。

<a id="boundaries"></a>

## 适用边界

- 本流程用于补全设计。单图无法确定深度、背面结构、附件、对称性和实际尺度。
- 在记录中区分**已观察**（来自原图）、**推定**（对隐藏设计的解释）和**未知**（证据仍不充分）。
- 线稿用于表达设计轮廓、面板边线和结构。要求真实拓扑线框时，交给 `blender-python-modeling` 从三维模型生成。
- 制造、装配、配合或精确尺寸需要实测、CAD 或经过校准的多视图。
- 默认使用内置图像生成工具。只有用户明确要求或确认时才使用 CLI 或 API 替代。

<a id="choose-the-requested-deliverable"></a>

## 根据用途选择交付内容

用于建模时，先明确哪张视图会影响实际建模决策。复用能约束目标区域的原图，只补缺少的控制方向，逐一审查原图忠实度和跨视图一致性。交付独立视图、锚点和允许建模的范围。只有用户需要展示线稿或线稿有助于解释约束时才制作。已有一致的粗模可用于解释隐藏关系时，可使用其正交渲染，但应标明其模型来源。

<a id="character-accessories-in-construction-views"></a>

### 遮挡建模的配件

先在 A 上圈出配件与主体的接触区域。大型背包、外挂货箱等若挡住主体轮廓、关节或接口，分别生成**无遮挡主体多视图**和**各待独立建模配件的多视图**，再以穿戴或装配图说明如何合回。记录同一部件名、安装侧、朝向、相对尺度及双方对应的接口。分别查看拆出后的背面与接触面，将原先不可见的部分标为推定。整体造型的一部分若无法合理拆下，保留主体结构，用局部多视图说明。

先选同一刚性基准边、安装面与上／下锚点，冻结软带的佩戴或展开状态。对成对软带分别追踪上端至下端；用相邻零件中心的有符号横向、深度和高度差核对三面投影。逐面量同一轴向的投影长度，并在侧面验证离面间隙。局部与整件的接口须能配回同一个位置。操作见[拆件配准与手掌方向](references/pre-model-review.md#register-detached-parts)。

**人物配饰。**

从第一张已定姿势图到后续多视图、特写与线稿，都应沿用同一配饰清单。登记原图可见或用户指定的物品、数量、佩戴侧、连接点及遮挡的特征。仅凭角色职业、风格或不可见背面不能推断出额外装备。无依据且未要求的道具不添加。

- 保留一体服装和能识别角色的细节，包括腰结、原图中可见的短带尾和发绳。数量、长度按原图；背部连接不清不能作为增加飘带的依据。
- 可拆物品若在控制视图中遮住脸、手、颈、躯干轮廓或四肢间隙，生成人物独立施工图。物品属于交付范围时，以原图或已标识的局部为依据另生成物品图。每套图内保持同一构型，另留穿戴原图或装配特写，记录侧别、相对尺度、遮挡和连接点。去掉物品后露出的身体表面属于推定。
- 若服装是角色的标志性一体结构，或用户明确要求持物／穿戴姿势，保留整体视图。仅在建模需要时补无遮挡的身体或连接特写。标明每份文件的主体及控制范围；物品图约束物品，装配图约束位置。

按[配饰提示词](references/prompt-recipes.md#accessory-scope-for-character-construction)生成，并在[建模前](references/pre-model-review.md)查看实际图片，排查增添、遗漏和遮挡。

<a id="follow-up-from-blender"></a>

### Blender 精修过程中补图

局部多视图也可单独交付，适用于一体结构和可拆件。例：耳根正面位置清楚、侧面厚度和后缘走向不清时，在整图标出耳根与头部连接区，单独生成侧面和后面局部图。每张带上相邻头部轮廓，注明放大倍率或共有锚点，以便配回主体。若现有裁图已能解释问题，直接复用。

建模或精修发现局部不清时，接收原图、已通过的视图、目标部位和具体问题，例如肩带在肩后连到哪里。沿用已定姿态、方向和锚点，只补缺少的方向或局部，保留已通过面板。将补图与原图及邻区对照，标明隐藏结构的推定。将补图放回原图集复核。整套重新通过后，返回冻结的干净视图、生成记录、输出哈希、视角、裁框、来源及已审范围，供 Blender 重新核查。

<a id="default-deliverable-for-a-full-design-sheet"></a>

## 完整设计稿的默认布局

先从用户参考图输出[不对称清单](references/inference-contract.md#choose-five-or-six-views)，随清单写明保留一个或两个侧视图的依据；提示词、审图和线稿沿用同一份清单。左右对称有依据时采用五视图：正面、标准侧面、背面、顶面、底面。不对称或对称性未知时采用六视图，分别提供左右侧。仅按请求或在有助于理解体积时加四分之三视图，尺寸仍以控制视图为准。完整稿采用四行三列。

| 对称设计 | 第一列 | 第二列 | 第三列 |
|---|---|---|---|
| 渲染第一行 | 正面 | 标准侧面 | 背面 |
| 渲染第二行 | 顶面 | 底面 | 可选四分之三视图或留空 |
| 线稿第一行 | 正面 | 标准侧面 | 背面 |
| 线稿第二行 | 顶面 | 底面 | 对应斜视线稿或留空 |

| 不对称或对称性未知 | 第一列 | 第二列 | 第三列 |
|---|---|---|---|
| 渲染第一行 | 正面 | 左侧 | 右侧 |
| 渲染第二行 | 背面 | 顶面 | 底面 |
| 线稿第一行 | 正面 | 左侧 | 右侧 |
| 线稿第二行 | 背面 | 顶面 | 底面 |

主体完整入画、居中，各面板共用正交比例和稳定锚点。尾巴、道具等改变包围框时保留共享尺度，避免分别缩放各张图。采用与主体全部外缘颜色和材质有足够区分度的纯色背景，默认高饱和洋红；主体含洋红时另选明度和色相都易区分的背景。渲染使用近似正交投影及柔和棚灯，线稿保持高对比度。仅按要求添加尺寸、商标、水印、场景或说明文字。

为有朝向的主体先确定基准方向，例如“侧面和顶面均头朝画面左、尾朝右”。有活动部件或关节时，按[姿态与构型规范](references/pose-and-configuration-normalization.md)锁定姿态。移动正交相机取得各面，不因某张图遮挡而移动四肢、关节、尾、翼、操纵面、门或工具。

与 Blender 交接时写明用途及控制姿势。固定姿势成品从首图、各控制面到粗模均沿用指定姿势。可复用绑定角色或用途未指定时，类人主体默认采用 A pose；若绑定已有约定，沿用约定的中立姿势。以下以 A pose 为例。先核对一张双臂自然斜向下外展、手与躯干分离、双脚略分开的参考，再锁定姿态出各面。为绑定而转换姿势时，将原动作图单列为造型参考。非类人对象按[类别与投影依据](references/pose-and-configuration-normalization.md)选择固定构型。

向 Blender 交接前，对实际生成图执行[建模前审阅](references/pre-model-review.md)，连同源哈希、区域、冲突和状态 `passed`、`partial` 或 `blocked` 一起记录。生成前列明本次建模所需的控制视图。修后候选须放回同一套图，与其他所需方向复核姿态、比例、轮廓、遮挡及连接关系。只有整套齐全、原图忠实度和跨视图一致性均通过、建模冲突已解决，才将状态记为 `passed`，冻结干净控制图与哈希并交接。`partial` 和 `blocked` 留在本技能内继续审阅。事后渲染模型不能补证建模前的审阅。

- **仅供预览**：披露后可保留轻微姿态、构型、比例或锚点漂移。
- **可用于 Blender 粗模**：姿态和构型、轴向、地面或原点、语义锚点和正交尺度均须通过一致性检查。未通过时仅作设计参考。

<a id="workflow"></a>

## 工作流程

1. **检查输入。** 将原图作为设计依据。若仅有本地文件，生成前用 `view_image` 查看。记录原图是正面、侧面、背面、顶面还是四分之三／透视视图。
2. **登记依据。** 阅读[推定规则](references/inference-contract.md)与[原图忠实度](references/source-fidelity.md)。生成前登记原图哈希和识别主体所需的形状、数量、连接等可见特征。区分忠实还原与用户主动选择的重新设计。
3. **决定视图数和目标。** 先决定本次需要整件、拆件还是局部，再选择能约束目标部位的方向。完整图集在有依据或用户选定左右对称时用五视图，其他情况用六视图。默认采用一种一致的解释；隐藏结构有实质不同的合理方案，或用户要求变体时，再提供其他方案。
4. **生成渲染视图。** 以输入图为依据，先看主体配色，再确定整套的纯色分离背景。完整稿在同一张两行三列图中生成五或六个渲染面板。建模图根据可信锚点和相机约定补面。参见[提示词配方](references/prompt-recipes.md)。在精模之前明确投影预期，例如竖直的花盘、车轮和盾牌从上、下方看应以薄边为主，朝上的宽面从顶面看应宽、侧面看应缩短。仅标记 TOP 不足以证明投影正确，生成线稿前须审查。
5. **出线稿前审图。** 发髻等朝向敏感的部件应在实际视图上标出特征点，执行[方向校验](references/consistency-review.md#directional-landmarks)。将生成区域与原图对照，填写[原图忠实度记录](assets/source-fidelity-review-template.json)。再独立检查跨视图的数量、位置、轮廓、比例、色块、对称性、方向、姿态、构型、锚点、尺度和投影。控制视图存在局部轮廓偏差时，先复用能约束该部位的可信视图。确需修图时，按[轮廓标注与复核](references/pre-model-review.md#annotated-contour-edit)提交干净底图和同构图标注副本，核对修改后的两侧边界及邻区。
6. **按需合成图集。** 固定已通过的渲染图，分别生成匹配线稿，再组合成四行三列。线稿漂移时降为补充证据，或从已审粗模提取轮廓；避免生成伪拓扑网格。
7. **验收与返修。** 按[跨视图一致性审阅](references/consistency-review.md#severity-and-iteration)检查实际图像。制作任务出现可定位、可修正的错误时，保存首候选与审阅结果，立即修正受影响的面板；缺面就补画，投影错误就按指定相机方向重新生成该视图。将修后图放回整套，复核原问题和跨视图关系。仍有可处理的问题时继续返修，整套通过后按[建模前审阅](references/pre-model-review.md)交接。
8. **交付。** 预览任务可直接展示图像。项目任务保存原图、生成图、生成记录、原图忠实度及多视图审阅。进入建模时提供独立完整视图或准确裁框、标签、共用尺度和原点、锚点及每个区域的可靠性与冲突。分别报告原图忠实度、一致性和校准状态。由 Blender 技能建立参考工作区并实际核查导入后的配准。

<a id="escalate-to-a-model-backed-sheet"></a>

## 转入基于实际模型的视图制作

需要严格的跨视图剪影、真实拓扑线框、可控尺寸、可动画网格、多轮无漂移修改，或 `.blend`、GLB、FBX、OBJ、STL 时，交给 `blender-python-modeling`。把生成图作为推定依据，制作规范姿态粗模，渲染真实正交相机，比较剪影，再用模型轮廓或线框替换生成线稿。

向 `blender-python-modeling` 交接时注明已观察、推定、未知和相互矛盾的区域。针对孤立的 AI 描绘错误，依据原图及一致的解剖或机械关系做最小修正。证据不足且不同选择会实质影响设计时，请用户判断。

<a id="completion-report"></a>

## 完成报告

报告原图视角、最终图集与单独渲染图路径、标准朝向和对称性假设、姿态或构型、坐标约定及锚点。说明各视图控制的区域、采用哪个侧面、关键推定与未知项、线稿来源，以及图集仅供预览还是可进入 Blender 粗模。若不能用于粗模，列出具体冲突。
