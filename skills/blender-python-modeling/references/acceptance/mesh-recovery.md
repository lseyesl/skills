# 网格恢复与数据迁移验收

1. 按用途声明闭合/开放、轮廓、最小结构和预算，分别检查原网格与求值网格；保存原高模与派生结果。

2. 转移前列出源/目标组、UV、颜色和法线；Topology 对应需身份依据，数量相等不是充分条件。

3. 检查未匹配/超距离/跨区域数据，权重再跑关节，UV 再看棋盘，法线再看目标材质。

4. 正确样例：合法开放衣片、已知对应的变形副本；缺陷：缺面闭合实体、跨指权重污染；替代：手工低模或不同顶点排序但独立空间映射正确的网格。

5. 自动网格完整性通过不能认证可变形性、打印厚度或参考形状一致。

来源与采用边界见 [制作来源](../sources/production-sources.md)。
