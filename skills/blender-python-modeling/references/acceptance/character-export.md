# 角色绑定与导出验收

声明平台、格式、影响数、FPS、动作列表、根运动策略、尺度及容差。检查 editable source 与 export copy 分离；只请求基础绑定时导出项可不适用，不允许因此宣称完整动画交付。

- 结构：目标网格的 Armature、骨层级、静止姿态、deform 组完整；脚本检查未赋权、权重和与影响数，控制/遮罩组不混入计算。
- 行为：按请求运行基础 FK、完整活动范围或行走周期，检查实际求值表面；走路接触按角色交付契约检查足底而非踝部目标。
- 导出：隔离重载或目标引擎检查骨轴/尺度/层级、动作名称和帧范围、根运动、形态键、材质及纹理。逐项记录比较结果和证据路径。
- 回归：源动作、形态键对应、非目标数据保持可用。

反例应覆盖未赋权顶点、权重正常但肩部塌陷、源场景通过而重载丢失动作；合法替代骨骼命名/控制方式不因与黄金文件不同而失败。未重载不能认证 export verified。

使用 `character_rig.rig_inventory` 核对持久骨架与权重，用 [隔离交付](../production-workspace.md) 对适用的线性蒙皮进行声明帧顶点云、三角面、骨层级、skin 和 clip 对照。曲线/形态键/非 Armature 修改器和复杂 shader 不能被默默丢弃；先制作并验证导出副本或选择对应适配器。骨架在源文件里不存在、clip 未制作、只运行过临时探针时直接未通过相应用途。

预算来自任务的实时目标；检验实际求值后的全角色总量，而非只算基网格或单个部件。低于预算不是形变/相似度通过；超过预算也不能通过无审阅减面来消除。按 [可用资产分级](usable-asset.md) 区分静态源、绑定完成与动画交付。
