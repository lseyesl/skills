# glTF 交付与优化验收

1. 保留导出/优化前后输入哈希、工具/消费者版本、目标格式与扩展、明确的收益目标和回归约束。

2. 独立 Validator errors 为零才称格式检查通过；警告逐条分类。blocked/未运行不是合法性通过。

3. 隔离重载并在目标查看器验证静态/动画对应范围。保护节点/挂点、材质、动作、形态键、交互与接触；格式通过不能替代这些检查。

4. 正确样例：标准有效 GLB；缺陷：坏引用/坏二进制、优化后节点丢失；替代：支持的外置 .gltf 资源与嵌入 GLB、保留功能的不同拓扑。

5. 数值减面/文件变小但保护项退化，不能认定正向；样本不足、未测运行成本或消费者未验证保持 unknown。

来源与采用边界见 [制作来源](../sources/production-sources.md)。
